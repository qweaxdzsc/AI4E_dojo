# Dojo 研究任务入口

先从[研究任务导航](../../../.context/tasks/research.md)选择当前任务，只阅读对应必读集合；遇到跨模块交接再沿该页进入模块索引。

- 网络、损失、数据与步骤变化优先复用示例中的普通函数和显式 Python 连接；不要复制训练循环。
- 更新策略改变可能使原检查点不相容。区分重新初始化权重与完整恢复，保留原数据顺序、归约和算法更新时机。
- 验证实际变化、短训/恢复和固定输出读回，目录或导入存在不代表可用。
- 新模型接入使用[现有集成技能](../dojo-integrate-model/SKILL.md)，不以此研究入口跳过原版复现与准入。

功能说明与示例是唯一使用依据；本技能不扩大当前任务、计算预算或正式服务操作授权。
