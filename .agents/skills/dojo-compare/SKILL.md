# Dojo 对照实验设计

把用户的研究目标变成可执行、可复核的对照协议。至少包含**白板组与 Dojo 组**；数据集、模型、有无指定基线、分组方法、重复次数、优化轮数、设备和时间门槛均由本次问题决定，不继承历史实验的具体数值。

本 skill 属于**主控会话**，不能注入实验组，也不能把主控总计划、其他组信息或隐藏评价资源交给实验组。Dojo 组按协议获得冻结的研究 Skill、GUIDE、帮助、案例与运行时；它们是待评价的干预材料，不由本 skill 另加采用率要求。

## 确定本次要回答什么

- 从用户已有选择补全：科学输入/输出、精度主指标及聚合、推理延迟的统计量和测量范围、训练时间期望、基线条件、轮次、资源和总成本承受范围。缺失且会改变任务的问题才询问；未确认的值标待定，不暗自沿用旧模型或门槛。
- 精度通常在满足推理门槛后优先，按用户当前排序冻结；编码时间、编码token及其他成本分别比较，不擅自合成总分。
- 选择足以回答问题的最小实验设计，解释因素、共同控制条件、随机化/执行顺序及独立重复。连续优化轮是同一会话的重复测量，不是独立样本；无重复时报告描述性差异，不虚构显著性。
- 对照若是“白板”对“框架＋案例＋文档＋Skill”，只能估计整套交付效果，不能单独声称Skill的因果收益。工具交叉使用、协议偏离和未完成组保留并标注，不静默删掉或重分组。

## 选择数据与定义 baseline

先核实来源、许可、可用原始数据、独立样本单位、字段/身份/单位及评价可行性。根据科学问题选择难度；若目标是数值模拟代理，应确认标签来源和预测任务，避免解析解、样本记忆或恒定背景即可获胜。设置简单参考预测用于诊断，但不自动增加优化组。

按真正独立的轨迹、几何、工况或对象切分训练/验证/隐藏测试，先审计重复和近重复。参数拟合、统计和派生训练缓存只用训练分片；验证用于开发选择；隐藏测试只用于冻结后评分。旧数据或模型训练语料的曝光范围如实说明，重新打乱不等于全新盲测。

明确用户要比较的起点，不能把以下材料混为一谈：

- **给定网络基线**：两组得到相同网络定义、初始化和科学配方；网络源码不夹带数据处理/训练工程。round-00由各组实际完成数据准备、装配和完整训练；逐项冻结采样、尾批、归约、归一化、验证和保存规则，防止默认值改变科学含义。
- **不给参考模型**：不交付模型源码、权重、名称推荐或历史优胜方案；由会话理解、搜索和选择首个模型。先登记首个方案的训练/选择规则，完成后冻结为初始点，之后才计优化轮。失败修复留档，不能把无限择优搜索藏在round-00之前。允许自主选择与另一组相同模型。
- 用户明确提供成熟工程时，说明共同交付范围及是否还考察数据准备；不能把工程迁移实验称为从原始材料独立实现。

默认只给原始训练/验证数据、科学说明、依赖声明与提交接口；各组自己做读取、检查、统计、窗口/采样、缓存和训练装配。主控可筛选复制原始文件，不提前交付整理张量、统计或派生缓存。Dojo通用案例可以被自主发现，但不能混入主控历史实验的专用解法或结果。

## 用真实预实验确认可行性

在启动正式会话前安排仅使用训练/验证的预实验，确认完整baseline训练时间、基本学习效果及完整输出的推理延迟。规划阶段可先估算并标明依据和未知；随机输入或缩小预算测速不能替代最终真实完整配方验收。

冻结任务的输出范围、精度和计时口径后再测：原始输入在约定位置到完整输出可用，计入必要处理、传输、全部前向/滚动及反变换；明确batch、设备同步、预热、重复、P95等聚合、模型常驻和冷启动。避免把抽点推理当完整场、把单步当完整预测或预缓存答案。

预实验不满足要求时先修订选型或协议，再冻结；不能事后截断epoch、缩减输出或放宽门槛冒充通过。主控的代码、统计、权重与结论不交付实验组，预实验成本单列。给定baseline的训练时长期望不自动成为所有优化轮的硬上限。

## 独立会话与隐藏评价

- 每个单元使用全新正式会话，组内连续优化；不fork主控、不用继承主控上下文的子agent代替。每个会话绑定独立组级工作根，实验在其下独立ID目录中；不能绑定共同父目录，组配置只含本组信息。
- 独立环境、HOME、缓存、临时文件与会话状态；关闭个人记忆、其他项目规则、非协议Skill/插件和本机资料连接器注入。共同依赖采用最小只读白名单；隔离所需的组内材料独立保存并核摘要，不因此在主控再备份一份。
- 实际预检本组读写、其他组/比较区/全集拒绝、父目录列举拒绝、链接和子进程逃逸拒绝、恢复后的边界及加速器可用。覆盖所有启用的本机工具和本机服务旁路；cwd或提示词约束不等于强制隔离。缺能力时先解决启动器，不宣称已隔离。
- 互联网和外部依赖策略按协议一致；若允许公共网络，明确公开测试数据再获取风险和来源审计能力。白板组不预置Dojo；自行获取时按实际记录处理，不能假称始终未用。
- 正式阶段固定研究Skill、框架与资料版本。主控可以观察，不能一边比较一边给某组补课或改Skill。若研究目的就是动态改Skill，另行定义设计，不能沿用固定干预的结论。
- 每轮冻结候选；只给本组开发验证反馈。所有相关会话最终选择冻结后，才开展隐藏评价。推理器只读冻结候选和输入，无真值/网络；可信评分器读预测与真值，不执行候选代码。隐藏结果与异常详情不回写实验组。
- 最终选择只根据验证；最终、最后一轮、事后测试最优分列。测试后不能修复候选再选；基础设施问题仅原样重试。共享硬件计算错开，排队单列。

## 产物归属与存储

- **实验组保存实体，主控只保存索引、摘要和总结。** 数据、准备产物、代码、检查点、预测和依赖由独立会话在本组案例内保存；主控不得再复制全套数据、安装包、真实环境或逐轮冻结产物。recipe验证和复用审计同样引用已有案例，不另建完整备份。
- 每轮冻结在组内完成：固定候选文件及其内容修订，后续轮次不得覆盖。主控索引记录组/会话/轮次、产物用途、受控路径、大小、内容摘要、环境修订及最终选择；读取和评价时核验引用。缺失或修订不符时明确失败，不静默改用最新文件。
- 每组保留实际运行环境；逐轮记录Python/平台版本、精确锁定的依赖、框架wheel或源码摘要及重建方式，不逐轮复制虚拟环境、site-packages或依赖缓存。依赖变化才在组内登记新的环境修订，需重建时按锁定材料验证；不能以未锁版本的requirements或可变环境冒充旧轮次环境。
- 隐藏评价通过最小只读授权访问索引指向的候选及对应环境，仍隔离真值、网络和其他组；主控持有的隐藏数据与评分证据不向实验组开放。主控新产生的隐藏预测仅保存在受控评价位置一份，按协议保留期限管理，不复制已有组内数组。
- 主控预实验或独有验证产物并非天然重复：保留必要指标、配置、报告和索引，大型中间数据按协议安排保留与清理。清理前确认可重建性及后续消费者；不得因日期较早就删掉当前实验引用的材料。既有评价器若依赖主控备份路径，先改为索引读取并验证，再清理备份；本skill更新不自动授权修改或删除正在运行的实验。

## 生成可执行计划及报告

使用[计划骨架](references/plan-outline.md)组织本次协议，填入实际选择和证据；未确定项写清由什么预实验解决。计划不是执行授权；用户只要设计时不创建实验会话或启动训练，已获授权的工作不重复询问。

生成计划和审计最终结果时读取[计量与报告口径](references/measurement-report.md)。主控交付至少包含：

1. 各组初始点和各轮**精度折线图**，验证/隐藏分开，标最终选择、延迟不合格和失败。
2. 各组**编码时间消耗折线图**，逐轮及累计，训练/准备/评价等成本分列。
3. 各组**编码token折线图**，逐轮及累计，缺失与混合活动区间显式呈现。
4. **Dojo利用率与代码覆盖量**：实际承担的框架职责、适用能力利用率、本地来源复用及import背后的展开实现量；给分子分母、源码/执行证据和自写代码分类，不能只有百分比。
5. 方法、延迟、完整成本、复制案例/自定义组件、失败与证据缺口、Skill导航问题和真实框架缺口，以及CSV/JSON明细与可追溯产物。

只把有证据的阶段标完成。没有真实数据时交付计划和报告规格，不画虚构结果。图表正确不证明隔离、成本完整或Skill行为收益；分别列科学、隔离、计账与复用审计状态。
