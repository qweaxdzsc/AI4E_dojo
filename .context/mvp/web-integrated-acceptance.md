## 范围与责任

主 Agent 管理公共契约、依赖、架构和总验收；visualization 管理 viz 与查看器；algorithms 管理算法、数据与薄案例；platform 管理 task/server 与宿主页面。三个子 Agent 均为 GPT-6-Astra、中等推理，无下级 Agent。共享工作区保留原有修改，全部工作区 diff 不等于本轮新增。

项目与任务管理、固定版本详情及比较、文件、任务第 2–7 步接入真实服务。报告、批量派生和排队运行未开放。归一化统计不可手工填写，模型采样归 `model.sampling`，旧单键兼容、双键拒绝；相机联动默认关闭。正式运行与试跑分开，监控只读取真实记录。完整架构只维护于唯一架构文档第 19 节，模块索引及 PRD 不另造架构真源。

## 四组合真实链路

主 Agent 经 HTTP 保存阶段配置、提交 task 原有运行、读取实际 recipe 产物，独立完成以下四组合 rawprep → trainprep → train → post。汽车 train 1 / test 1；NASA train 8 / validation 1 / test 1。使用完整目标网络、单轮训练，没有以缩小网络替代；这是少样本短训交接验收，不是生产训练精度验收。

- ShapeNet × AB-UPT：18,634,180 参数，PT，真实汽车完整测试样本 3586 点。
- ShapeNet × Transolver-3 surface：11,332,033 参数，PT，3586 点。
- NASA CRM × AB-UPT：19,736,644 参数，Zarr 直接准备与训练，454404 点。
- NASA CRM × Transolver-3：11,335,876 参数，Zarr 直接准备与训练，454404 点。

每组 `web-integrated-results/{case}.json` 保存真实运行身份、配置与代码摘要；`{case}-{stage}.log` 记录提交过程。修复 `post.export_vtk` 未被消费的问题后，沿用已训练 checkpoint 重跑 post，未重训或覆盖历史运行；原 post 保留于 `previous_post_runs`。`{case}-post-export.log` 和 `{case}-preview.json` 保存最终导出及独立对照。

主 Agent 用独立 torch/VTK 读取与 HTTP 张量分页、显示二进制逐值比较，四组 `tensor_values_equal` 和 `mesh_coordinates_equal` 均为 true。网格包含原拓扑和原始身份。NASA 两模型严格差值与独立张量减法相等，见 `nasa-http-difference.json`；不同实体、坐标、拓扑或未知单位拒绝，不插值。

真实模型图来自 TorchVista 实际前向。四组算法跟踪记录见 `web-algorithm-results/`；平台自动化实际打开 TorchVista SVG，截图 `web-integrated-results/screens/real-torchvista.png`。四组合训练由 HTTP 驱动；浏览器自动化覆盖代表性页面配置、正式多输出执行、固定产物选择及真实图形，不声称四组每个训练按钮都在浏览器重复点过。

## 公共接口及可视化

spec 统一 AssetRef、字段身份、辅助 Operation、DisplayAssetManifest 和 SceneDocument；生成 TypeScript 类型。浏览器不提交任意绝对路径。task 保留研究执行事实，辅助 viz 操作由服务管理；二者生命周期分离。

相同修订和转换选项共享真实 viz 进程，调用者取得独立 subscription_id；取消一个订阅不终止其他订阅，最后订阅取消才回收进程。成功结果经范围和修订检查后复用。空体取消保留明确停止整个操作的兼容语义。已结束操作不会被迟到事件复活。

VTK 支持基础查看、切片、裁切、阈值、点标量等值；体网格在科学过滤前保留。点、单元、生成实体身份明确，二进制数组与 JSON 清单分离。最多四窗口，联动显式开启，资源有预算、引用计数和释放。真实 NASA 导出网格在浏览器显示，并核对 454404 个原 ID 和拾取；真实差值显示也已验收。解析场/构造网格仅用于精确过滤器测试，未冒充真实数据。

相机联动逐项校验完整固定源身份，跨源需要显式坐标空间和坐标单位，恢复时重新验证。坐标声明经实际 post 网格 FieldData、差值 sidecar、受控服务及 viz 清单传播；浏览器不能注入。合法跨源使用明确声明米制坐标的解析网格经真实服务验证；实际 NASA 源属性缺坐标单位，继续明确拒绝未知空间跨源联动，没有为测试猜单位。

页面测试位于 `packages/ai4e-web/e2e/`，启动真实 API/Vite 后执行；不安排人工手点。不以少量布局断言声称所有视口、所有错误状态都像素一致。首期无自动配准/插值、完整 ParaView、高级重建、生产压力或训练精度承诺；未有记录的升阻力等曲线明确不可用。历史报告代码保留但整合入口不开放。
