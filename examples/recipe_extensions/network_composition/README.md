- [残差U-Net](resunet/README.md)：基案例classic_networks.darcy，替换编码与瓶颈。
- [U-Net注意力瓶颈](unet_transformer/README.md)：基案例classic_networks.darcy，显式网格与token转换。
- [CNN-RNN](cnn_rnn/README.md)：基案例classic_networks.double_cylinder，保留真实时间和空间身份。

同层四个Python文件是源码组合验证入口；各扩展携带所需普通组件，物化后没有对本目录或仓库的隐藏依赖。变更组件后同步对应覆盖副本并核对字节一致。派生范数只是有声明数组的保存读回示范，不将未知单位或混合量范数称为速度。

当前源码和组件非训练验证已有证据；统一真实训练、复制后完整流程、恢复及wheel验收仍由主控执行。
