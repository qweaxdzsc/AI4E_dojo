# PCNO 圆柱研究模板

本模板是 PCNO 谱/局部空间融合方法的二维时空变体，不是原地热四维网络或论文精度复现。

当前可训练案例为 Double Cylinder：5条训练、1条留出验证，历史3帧预测12帧、间隔10。
预测窗口起点为0、120、…、840；相邻窗口的目标帧不重复，共评价96个时刻，不称为1000帧滚动预测。
未来真实SDF只用于训练损失及离线评价共同有效域，不进入网络。
CylinderFlow官方8/2/2轨迹已获取，但P1散度未通过1%准入，不开放其训练。

复制整个目录到仓库外，绑定 `inputs.rawprep.source` 为原始 `double_cylinder/couple` 目录。
`run_root` 与 `data_root` 应分别指向代码目录外的运行、科学数据目录；默认相对路径需要按实际研究位置覆盖。
运行 `uv run --no-sync python pipeline.py --config config.yaml`。
也可用同一目录作为 `ai4e_task.new_task(..., source=...)` 输入。

阶段：rawprep核验来源；trainprep只保存训练统计/窗口索引；train显式预热后分叉监督和物理组、共用结构分支；infer固定权重预测；post仅读取固定结果。
独立执行使用 `inputs.<stage>.<name>`；输入与上游返回冲突时报错。
中断恢复将 `inputs.train.resume` 指向数据目录的 `train/resume.json`，完整恢复要求科学配置不变。
来源数据只读且外部绑定；复制准备清单并不复制或代替原始数据，外部运行仍须可访问该来源。

本轮默认Adam/学习率0.001、CPU4线程、500次更新；前20%仅数据，随后20%爬升梯度/散度权重至0.1。
监督组具有相同梯度损失，仅散度权重为0。散度计算采用来源相符的交错前向通量，不对人工清零场求导。
`components.network` 可替换为普通构造函数；入口参数参见案例配置与组件Docstring。
修改预算或结构后开始新实验；不能冒充原目标精确恢复。

最终报告分列预测误差和连续性，纯短训不保证优于末帧保持。
安装、Task、扩展和科学准入的实际结果见仓库PCNO圆柱验收记录。

## 选择与改写说明

双圆柱二维时序监督；窗口、速度与连续性约束由案例明确定义。

数据形态：regular_grid, field_sequence；训练机制：iteration。

### 具体修改位置

- 数据来源、预算和设备参数先在 `config.yaml` 调整；配置加载规则见 `configuration.py`，步骤调用和返回值交接见 `pipeline.py`。
- 配置已声明的可替换入口：`network`。读取对应阶段实际消费位置，再替换普通用户函数/对象；名称出现在列表不代表能跳过科学兼容检查。
- 保留原准备引用、训练运行记录与恢复交接；新增输出由计算步骤保存，推理与后处理从明确产物读回，不重写训练循环。

### 运行与读回

- 运行前填写自己的输入与输出目录；先按本页原有命令/阶段说明执行短程连接验证。更改模型或科学定义时不得沿用不兼容检查点。
- 核对真实运行报告、检查点和固定预测；存在派生结果时必须从后处理读回。恢复与独立推理分别验证，不以导入成功替代。

### 适用边界

- 数据字段、科学目标与检查点兼容性按本案例定义；不能直接套到另一任务。
- 工程运行、缩小预算与论文精度范围以案例正文和对应证据为准。
