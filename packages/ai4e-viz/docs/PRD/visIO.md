## 一、配置资产与显式输出

### 1.1 背景与定位

统一可视化资产保存、查询、报告引用和显式文件交付；处理算法属于具体可视化模块，旧数据读取保持兼容。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
 A[提取配置] --> B[校验修订] --> C[下载或报告引用]
```

完整流程：提取配置 → 校验修订 → 原子保存 → 显式请求输出 → 登记成功文件 → 下载或报告引用。

### 1.3 业务状态机

配置：新建、已保存、修订冲突。输出：running、succeeded、failed、canceled；完成之前不能作为成功输出交付。

### 1.4 状态值说明

成功表示本次操作完整交付；失败保持原可用结果。未完成或被取消不得标记为已完成。本章不额外建立全局状态或数据库。

### 1.6 功能点详解

#### 1. 现行功能与使用约定

图片输出请求可显式开启透明背景，默认关闭；PNG 和 PNG 序列保留真实透明通道，MP4 拒绝透明请求。固定修订、视图和尺寸交给物理场生产器，输出不修改会话背景，也不包含临时编辑附件。

资产仅保存索引、来源引用和配置修订。PNG、CSV、PNG 序列、MP4 与实际视口 WebM 通过明确导出生成。时序输出提供帧进度、取消与下载；固定配置修订和选定视图在每帧保持一致。

后台输出使用独立计算场景。方向轴、图例、Probe 与时间进入实际画面。报告固定修订，新增输出不改变配置摘要。原 SQLite 读取兼容；新保存必须绑定任务。物理和图表资产共用索引，原图表读回即时重建预览。
