## 一、MCP

### 1.1 背景与定位

保留本模块产品需求，现行行为与未实现范围分项说明。底层内核能力、数据结构占位和其它模块的交互不算本模块交付。本轮整理不补未实现功能。

### 1.3 业务状态机

本章不另建统一业务状态机；已有草稿、版本或异步输出的状态沿用对应已实现操作。未开放操作没有成功状态。

### 1.4 状态值说明

已实现表示已有实际调用链；部分实现表示仅支持详解列明的范围；未实现表示保留需求，不能据目录或类型声明调用完成。操作失败保留原有数据，不生成虚假成功结果。
