## 一、输入资产与外部引用

### 1.1 背景与定位

负责数据登记、上传、摘要去重、列表详情、分类修正及历史、原始文件定位；数据解析和质量规则属于数据集模块。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
 A[上传或选择已登记来源] --> B[固定来源身份] --> C[交给读取模块]
```

完整流程：上传或选择已登记来源 → 固定来源身份 → 授权成员 → 校验修订 → 交给读取模块。

### 1.3 业务状态机

保留原资产与分类历史状态。外部绑定是会话上下文，不新增资产所有权状态。来源缺失、内容变化与越界分别报错。

### 1.4 状态值说明

成功表示本次操作完整交付；失败保持原可用结果。未完成或被取消不得标记为已完成。本章不额外建立全局状态或数据库。

### 1.5 功能点清单

独立 Vis 可选择已有数据或上传后登记；Dojo 既有数据只引用，不调用上传流程复制文件。外部引用固定修订及复合 VTK 依赖成员；会话内追加先完成加载，失败保留原绑定与工作区。

### 1.6 功能点详解

浏览器只提交已登记身份与受控成员，不提交任意服务端路径。保存可视化不触发上传、复制或原数据更改。历史记录、相对存储键和公开地址保持兼容，服务故障不能伪装成空列表。
