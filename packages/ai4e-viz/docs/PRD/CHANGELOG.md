# PRD 变更记录

## 2026-09-17 · 相机联动覆盖整个视图空间

- 开启相机联动后，当前全部窗口共用相机；不再要求来源声明同一坐标空间 ID。
- 已声明坐标单位不一致只提示，不拒绝联动。非法来源、跨项目和符号链接门禁不变。
- 详见 `visPhysField.md`。正式 5173→8000 须重装并换 Vis 后点验。

## 2026-09-17 · Surface LIC 远程交接防崩

- 选 Surface LIC 后先建显示、再出远程静帧，成功才打开拖转；交接中不向远程送手势。
- 无点向量、建图失败或第一帧失败只提示，恢复原表面/网格，不切半套远程，不弄死会话。
- 详见 `visPhysField.md`。正式 5173→8000 须重装并换 Vis 后点验。

## 2026-09-17 · 工作台色标、Probe 与视图联动

- 色标入口改到属性「显示设置」图标，弹层带当前对象名和「应用」；只写选中对象，右上角不再放色标设置。
- Probe「点选拾取」只留行名加一个开关，去掉重复按钮和说明。
- 新建窗口加号与分割菜单贴在按钮旁边。点窗即活跃，左侧眼睛跟随该窗，不重读网格。
- 折线图活跃时树只列出线段提取；去掉取样物理量，新应用取全部场，旧 `fields` 只读。
- 详见 `visPhysField.md`。窗体收紧与位置普通下拉已在正式 5173→8000 后处理三维页点验。

## 2026-09-17 · 工作台小修复收口

- 交互按下先分类：点住切面手柄只改平面；滚轮和拖空白只改本地视角，不要求后台同步相机。
- 几何、显隐、平面颜色刷新默认不夹带相机；只有标准方向 / 适窗 / 分屏才回写视角。
- LocalView 场景重载不再用未更新的 `render_cameras` 覆盖本地轨道；只在标准方向/适窗/分屏真正推位姿时同步。
- 删除平面移动里已禁用的线/种子拖动分支；流线与线段提取仍无拖动手柄。
- 着色、等值滑条、折线轴各自跟随该控件声明的物理量。窗口类型为三维渲染或折线图。
- 详见 `visPhysField.md`。正式 5173→8000 须重装并换 Vis 后点验。

## 2026-09-17 · 线段提取对齐 ParaView Line Chart View

- 线段提取仍是对象树独立对象；起点/终点/分辨率须应用。不提供视口拖线。
- 视口可新建「三维渲染」或「折线图」。应用线段提取后打开或激活 Line Chart View，折线画在视口区。
- 属性 X 轴：弧长、采样点序号、Points_X/Y/Z 及已取样场；Y 轴多选物理量。当前折线图视口改轴立即重画。
- CSV 导出当前图的 X + 所选 Y。旧修订缺视口类型或轴字段按三维渲染、X=弧长、Y=第一条标量读取，不回写。
- 详见 `visPhysField.md`、`visTaskManage.md`。官方对照：[Displaying data / Line Chart View](https://docs.paraview.org/en/latest/UsersGuide/displayingData.html#line-chart-view)、[PlotOverLine](https://www.paraview.org/paraview-docs/latest/python/paraview.simple.__init__.PlotOverLine.html)、[CSV 导出图表视口](https://www.paraview.org/paraview-docs/v5.13.0/cxx/classvtkSMCSVExporterProxy.html)。

## 2026-09-17 · 流线去拖动、形状与坐标轴实时

- 流线线段/球体/平面草稿不再提供拖动手柄；添加流线、选种子类型、应用生成和已应用「显示种子」保留。本期不做拖种子。
- 本地左下角坐标轴在轨道过程中跟随当前本地相机，不只等 pointerup / EndAnimation。
- 流线显示可选线或圆管，可调粗细；圆管可调圆周面数 3–64。写入 `style.streamline`，缺键按线、细、8 面读取，不回写历史。详见 `visPhysField.md`、`visEngine.md`、`visTaskManage.md`。

## 2026-09-17 · Probe 点选拾取可见开关

- Probe 属性提供「点选拾取」开/关；开着点模型出球，应用后出表；关着不拾取。切到其他工具或轨道时开关回到关，与后台一致。旧修订缺键视为关，不重写历史 spec。详见 `visPhysField.md`。

## 2026-09-17 · 等值滑条使用物理量范围

- 等值面滑条 min/max/当前值取所选计算物理量在当前网格上的实际标量范围，不再用归一化 0–1。
- 换场后重算；手填仍可越界。范围无效时占位并说明。旧修订不写范围，打开时现算。详见 `visPhysField.md`。

## 2026-09-17 · Surface LIC 着色跟随物理量

- Surface LIC 方向仍用三维点向量；换着色物理量后颜色跟随新标量或向量幅值/分量，不再保持纯色。旧修订缺 `lic.vectors` 按着色场或网格点向量读取，不回写历史 spec。详见 `visPhysField.md`、`visTaskManage.md`。

## 2026-09-17 · 辅助平面轨道不再被旧相机拉回

- 添加辅助平面后，旋转、平移、缩放都不得回到添加时的固定视角。本地 `view.update` 默认不序列化相机位姿；`render_cameras` 只在服务端主动改相机时写入。轨道占用覆盖转/移/缩，不只挡滚轮。详见 `visPhysField.md`。

## 2026-09-17 · 默认光照对齐 ParaView Light Kit

- 三维视图默认使用 VTK/ParaView 五灯套件，关掉自动单头灯；背光可见面由补光/轮廓光/头灯补亮，不抬材质 Ambient、不洗白色标。
- 阴影仍默认关闭，仅 Linux 远程可开。旧修订缺灯/阴影键按新默认读，不重写历史 spec。详见 `visEngine.md`、`visPhysField.md`。
