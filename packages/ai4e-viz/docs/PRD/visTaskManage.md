## 一、可视化配置与修订

### 1.1 背景与定位

为物理场与原有图表方法提供配置管理、推荐、参数校验和版本兼容。配置声明描述如何重建结果，工作会话和原数据由对应模块管理。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
 A[选择方法或读取配置] --> B[校验来源和参数] --> C[提交新配置修订]
```

完整流程：选择方法或读取配置 → 校验来源和参数 → 应用工作区 → 提交新配置修订。

### 1.3 业务状态机

未保存 → 已保存 → 新修订。冲突时保留旧修订，要求刷新后重试；失败不覆盖历史配置。

### 1.4 状态值说明

成功表示本次操作完整交付；失败保持原可用结果。未完成或被取消不得标记为已完成。本章不额外建立全局状态或数据库。

### 1.6 功能点详解

#### 1. 现行功能与使用约定

显示层新增可选色标样式，校验方向、位置、长度、厚度及字号；颜色自定义范围必须有限、完整且最小值不大于最大值，最小等于最大合法，省略范围表示自动。显示模式可写 `surface_lic`，并带可选 LIC 参数块；`lic.vectors` 可声明 LIC 方向场，缺省按着色场或网格点向量读取，不回写历史修订。纯色可写三个 0–1 分量，等高线线宽必须为正且不超过 20。流线可选 `style.streamline`：`shape` 为 `line` 或 `tube`，`thickness` 线模式不超过 20、圆管为正半径，`sides` 为 3–64；缺键按线、细、8 面读取，不回写历史修订。视图背景必须为三个有效颜色分量。矢量形状、缩放和空间采样为可选声明，缺省保持旧箭头、矢量模长及节点间隔；箭头尺寸只在箭头形状上校验。旧修订只读，不自动回写新增默认值。

物理配置版本2新增可选等高线自动分层和显示层辅助平面显隐声明；旧等值列表保持自定义模式，缺少辅助显隐默认开启。冲突声明拒绝，历史文件不批量重写。

物理场版本 2 分离 sources、pipeline、layers、probes、views、layout、link_groups/time；稳定身份独立于数组位置。计算字段与着色字段分开；视图具有各自显示实例，父子节点显隐不传播；保存和重开逐对象、逐视图恢复，隐藏父对象仍可显示子对象。版本 1 在内存转换，补基础显示与等价布局，历史文件与摘要保持不变。图表仍使用原版本及渲染实现。允许移除全部结果后的空物理工作区；不允许悬空处理依赖。流线缺起点类型按线段读取；命名面对象引用必须已在管线中且无环。切面参数含 `crinkle`、`triangulate`，剖切含 `crinkle`；流线 `helpers` 可含 `seeds_visible`；管线类型可含 `plot_over_line`，参数为两端点、分辨率 2–20000 与取样字段；折线图轴写在对象 `chart` 与视口 `chart`，不进入取样缓存键。Probe 点选拾取是会话开关，`pick_enabled` 缺键视为关，规范化不回写。视口可写 `type`：`render` 或 `line_chart`，缺省三维渲染；`line_chart` 可含 `source`、`x_array`、`y_arrays`。旧修订缺这些键按默认读取，不改写历史文件。保存的窗口类型仍可固定；实际出图是否远程不写进历史窗口字段。

修订只保存来源引用与参数。草稿、选择、端口、可视平面和原始数组不进入配置。预期修订防止并发覆盖；只写目标任务位置，不创建研究版本。旧流线只有起终点时仍可打开并按线段计算；配置版本仍是 2，不改历史修订。
