# 产物与证据等级

运行至少核对最终配置、`summary.json`、日志、`assets.json`、`metrics.json`、检查点和阶段数据目录。组件调用证明需要配置身份、阶段报告、状态变化和下游产物相互对应。

工程接线、状态或预测一致性、学习效果和论文级精度是四层不同证据。smoke 只覆盖第一层及部分恢复交接。
