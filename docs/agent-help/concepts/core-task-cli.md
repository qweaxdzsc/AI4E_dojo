# Core、Task 与 CLI

研究执行优先级是 direct `ai4e_core.run.launch`、同目录 `ai4e_task` Python API、CLI 便利包装。Core 证明研究流程自身能运行；Task 增加管理能力；CLI 只调用同一 Python API。

CLI 返回成功不能替代阶段摘要、组件调用、检查点、预测、指标和 post 的读回证据。
