# 错误索引

`KeyError/ValueError` 先查配置；`FileNotFoundError` 查阶段输入和路径；`ModuleNotFoundError` 查当前解释器与案例依赖；恢复结构错误查检查点；Task 状态错误查运行收据；结果缺失或不可比查资产和指标清单。

可用 `search_help(str(error))` 搜索结构化 `errors` 字段和正文。
