# 运行产物参考

运行目录通常包含 `inputs/config.yaml`、`summary.json`、`logs/run.log`、失败日志、`artifacts/assets.json`、`artifacts/metrics.json` 和 `checkpoints/`。数据目录按阶段保存处理数据、预测和 post。

以当前 `TrainingRun` 和案例 README 为准；文件存在必须与索引、摘要、内容摘要和来源身份一致。
