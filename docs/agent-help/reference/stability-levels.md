# API 稳定性等级

`stable` 是正式公开入口；`extension` 允许研究组合但承担局部领域契约；`advanced` 面向运行或管理高级控制；`internal-visible` 仅为源码可见性和迁移定位，不承诺兼容。

文档覆盖所有公开外观符号不表示它们全部升级为 stable。修改研究代码前同时核对稳定性和关联案例。
