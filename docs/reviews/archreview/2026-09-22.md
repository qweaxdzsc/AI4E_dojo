### 八层事实所有权与当前实现

- **spec** 拥有跨进程、持久化、展示的最小记录：来源、资产、指标、请求及引用；不拥有模型、算法或统一张量格式。当前 `artifacts/indexes.py` 和 `artifacts/inference.py` 分别承载公共索引与专用推理选择，不能将后者误认跨领域完整协议。
- **core** 拥有可复用计算、领域步骤、顺序执行和运行记录；不拥有项目/任务生命周期。`run/writer.py:129` 登记资产，`:155` 登记指标；路径、依赖摘要和科学口径由真实生产者提供，writer 不解释方程。保留公开 run 门面与自由函数连接。
- **contrib/application** 拥有数据集、模型专属配置和业务连接，以及需要科学知识的检查、评价与导出；不接管 Task 数据库和通用 writer。`aero_cfd/operations.py` 已提供可选 inspect/infer/evaluate/export，控制领域 `handoff.py` 已登记 split/phase，说明分层基础存在。
- **recipe** 拥有实际步骤与局部转换，Python 决定流程、YAML 提供参数；不应复制平台状态机。新增时空/外流案例仍通过领域连接交付资产，不要求各领域共用字段、损失和张量布局。目录存在不等于运行通过。
- **Task** 应拥有项目、任务、版本、配置修订、运行、固定输入、资产/检查点引用、失败和恢复；必须保留完整性与身份门禁，不能解释模型结构或科学兼容性。当前 R1/R2/R3 是这一边界的具体例外。
- **Server** 拥有授权路径、平台用例、官方选项目录、辅助操作和 Vis 会话适配；不拥有数值算法。`modules/inference/application.py:16` 经 Task 公共门面取候选，`modules/visualization/application.py:480` 经 Task 检查生成固定显示资产。`capabilities/model_cases.py` 的官方模型目录属于 Server，不能迁为 Task 模型目录。
- **Web** 拥有页面、草稿、请求与显示状态；研究运行终态由 Task 经 Server 返回。抽查 `src/modules/inference/api.ts:1` 的 HTTP/传输适配及模型/阶段索引，未见浏览器直接读取 Python 内部状态。此结论限抽查及内容未变，不是所有页面的运行时证明。
- **Vis** 拥有显示、预览、会话和导出；固定结果展示不回到 Trainer。必须区分“消费固定资产”和“生产诊断资产”：当前 `inspect/model_graph.py` 明确接收活网络/输入生产 HTML，不能声称整个 Vis 只接固定文件。此诊断能力可保留，拥有其装配的 Task worker 需要调整，见 R3。
