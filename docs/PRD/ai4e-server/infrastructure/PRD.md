## 一、平台记录与内容访问

### 1.1 背景与定位

为本机平台提供服务自有记录、内容访问范围和标准响应。研究运行仍由任务与运行产物拥有；基础设施不计算训练、物理指标或归一化统计。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
 A[请求固定对象] --> B[核对范围与修订] --> C[读取或原子更新] --> D[返回实际事实或明确缺失]
```

### 1.3 业务状态机

本章无独立业务状态。记录生命周期由场景、辅助操作和项目业务拥有。

### 1.4 状态值说明

内容变化、访问越界、修订冲突分别拒绝。已知业务码在 `error.message` 给出中文，`detail` 与 `error.code` 仍保留原码。原始统计中的非有限哨兵在标准 JSON 传输中为空值，不改变运行成功与失败事实。

### 1.5 功能点清单

1. 持久化与并发修订。
2. 受控内容访问。
3. 缺失统计传输。
4. 业务错误码映射。

### 1.6 功能点详解

#### 1. 持久化与并发修订

推理预检的来源失效、参数冲突和字段不可用应保留可定位原因；固定结果的CSV/Excel与数组下载统一使用已有受控文件引用和修订校验。只接受任务范围的结果，不接受浏览器指定服务器输出路径。

服务自有场景、比较和辅助操作在本地持久化。场景更新在同一事务核对修订再保存，两个编辑者不能互相静默覆盖。运行事实不复制成另一套执行状态。

#### 2. 受控内容访问

内容通过登记根与相对路径访问。预览与写出每次读取重新核对位置与内容修订；阶段输入列表可用路径加文件戳识别同一文件，避免切步时整份哈希检查点。符号链接外逃、私有路径和目录穿越拒绝。显示二进制只从服务分配的显示目录下载。

#### 3. 缺失统计传输

无最优评价时原始训练记录可能使用 Infinity 哨兵。HTTP 和事件响应将非有限数递归映射为空值；不填零、不改写原始产物、不把正常训练转为失败。客户端显示未记录或缺失。

#### 4. 业务错误码映射

已知冲突码在 `error.message` 给出中文说明，`detail` 与 `error.code` 仍保留原码，页面优先展示中文。平台数据集同名不同声明属于此类；`location` 写明 VTKHDF 等实际差异，不把并行线程写成原因。训练运行若请求合并准备，返回 `train_requires_preparation`。缺推理批次映射为 `inference_batch_not_found`，不能把缺 `state.json` 说成数据根未配置。

辅助进程关闭：服务 lifespan 结束只将自身非终态辅助操作标为 interrupted，终止后有界等待，超时 kill 并回收；取消使用相同回收机制，并清理取消/中断的显示缓存。task 研究运行不加入辅助进程注册表，保持独立执行及重启查询。

## 项目任务可视化交接

### 2.1 背景与定位

可视化服务独立启动并回收，宿主通过受控通信代理嵌入应用。内部上下文登记不向浏览器开放；写操作再次核验任务归档状态。每个请求携带上下文，不用全局变量切换任务目录。

### 2.2 核心业务操作流程图

```mermaid
flowchart LR
    A[选择任务与固定来源] --> B[打开可视化工作区]
    B --> C[调整并保存配置]
    C --> D[读取固定修订]
    D --> E[按需显式导出]
```

### 2.3 业务状态机

本章沿用任务归档状态；交互会话与导出状态由独立可视化模块负责，不在本模块复制状态机。

### 2.4 状态值说明

可写任务允许保存和导出；归档任务只允许读取既有配置。数据缺失或修订变化显示错误，不能作为成功重开。

### 2.5 功能点清单

1. 明确任务保存上下文。
2. 固定来源与配置资产交接。
3. 独立工作区与显式输出。

### 2.6 功能点详解

#### 1. 明确任务保存上下文

保存位置属于选定项目任务；不要求迁移原数据，不创建新的研究版本。

#### 2. 固定来源与配置资产交接

只保存引用、处理步骤与显示配置；输入修订和配置修订分别校验。缓存删除不影响读取配置。

#### 3. 独立工作区与显式输出

页面与脚本共享业务入口；图片、视频和提取数据只在明确输出操作时生成。配置保存和导出是两个操作。宿主代理三维工作台的 HTTP 与 WebSocket；服务进程必须带 `uvicorn[standard]`，否则页面会话已建立仍会 Connection error。
