# 平台记录与内容访问

## 一、平台记录与内容访问

### 1.1 背景与定位

为本机平台提供服务自有记录、内容访问范围和标准响应。研究运行仍由任务与运行产物拥有；基础设施不计算训练、物理指标或归一化统计。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
 A[请求固定对象] --> B[核对范围与修订] --> C[读取或原子更新] --> D[返回实际事实或明确缺失]
```

### 1.3 业务状态机

本章无独立业务状态。记录生命周期由场景、辅助操作和项目业务拥有。

### 1.4 状态值说明

内容变化、访问越界、修订冲突分别拒绝。原始统计中的非有限哨兵在标准 JSON 传输中为空值，不改变运行成功与失败事实。

### 1.5 功能点清单

1. 持久化与并发修订。
2. 受控内容访问。
3. 缺失统计传输。

### 1.6 功能点详解

#### 1. 持久化与并发修订

服务自有场景、比较和辅助操作在本地持久化。场景更新在同一事务核对修订再保存，两个编辑者不能互相静默覆盖。运行事实不复制成另一套执行状态。

#### 2. 受控内容访问

内容通过登记根与相对路径访问，每次读取重新核对位置与内容修订。符号链接外逃、私有路径和目录穿越拒绝。显示二进制只从服务分配的显示目录下载。

#### 3. 缺失统计传输

无最优评价时原始训练记录可能使用 Infinity 哨兵。HTTP 和事件响应将非有限数递归映射为空值；不填零、不改写原始产物、不把正常训练转为失败。客户端显示未记录或缺失。

辅助进程关闭：服务 lifespan 结束只将自身非终态辅助操作标为 interrupted，终止后有界等待，超时 kill 并回收；取消使用相同回收机制，并清理取消/中断的显示缓存。task 研究运行不加入辅助进程注册表，保持独立执行及重启查询。
