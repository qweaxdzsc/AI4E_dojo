## 一、离线比较报告

### 1.1 背景与定位

为研究人员表达已经计算完成的物理比较结果。仅依赖稳定产物与渲染库，不调用模型或训练器，不实现物理误差和切面计算，不扩展 Web 平台。

### 1.2 核心业务操作流程图


### 1.3 业务状态机

本章无独立持久业务状态，调用失败向调用方传播，比较进度由计算阶段记录。

### 1.4 状态值说明

本章无业务状态值，不把渲染成功当作训练成功。

### 1.5 功能点清单

1. 组合独立域结果
2. 关联图像与结果

### 1.6 功能点详解

#### 1. 组合独立域结果

同一数据集的表面与体积比较可合入一个离线 HTML；逐域展示模型的 MSE、MAE、相对 L2 与元素数。零真值范数显示不可定义。报告不预设训练轮数，预算和设备以源运行产物为准，避免更换实验预算后仍被标为单轮。

#### 2. 关联图像与结果

报告只读取成功比较产物并关联生成的 PNG。图像保存共同色标声明，数据和渲染分开，使研究人员可以检查底层数值后重新表达，无需重训。
