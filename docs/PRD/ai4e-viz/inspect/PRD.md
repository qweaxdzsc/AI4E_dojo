## 一、文件检查

### 1.1 背景与定位

为本机研究工作流提供文件检查。复用已有案例和任务事实，不增加算法、任务调度、报告发布或多用户权限。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
  A[选择研究对象] --> B[核对范围和输入] --> C[执行请求] --> D[返回真实记录或明确错误]
```

### 1.3 业务状态机

本章无独立业务状态；运行状态由任务管理拥有，检查和预览为一次请求的结果。

### 1.4 状态值说明

成功返回当前记录，失败说明输入、范围或读取原因；连接中断不表示运行失败。

### 1.5 功能点清单

1. 真实字段读取。

### 1.6 功能点详解

#### 1. 真实字段读取

文本列、NPY 与 PT 成员、HDF5 数据集、VTK 家族几何和场从文件读取。HDF5 若为 VTKHDF 根组则按网格检查，否则只报告数据集元数据；同构多样本组不把每个样本重复展开。未知格式和空网格/空存储明确失败，不生成示例字段。 已有案例和数据格式保持兼容，未支持请求不得静默转换。

## 二、模型结构图展示

### 2.1 背景与定位

展示 application 已生成的两档固定 HTML 与来源说明。Vis 不接收活网络、不猜模型属性、不反向调用 core；真实输入准备和模型专属阶段组织归 application，通用跟踪、状态保护及文件提交归 core ability。

### 2.2 核心业务操作流程图

```mermaid
flowchart LR
  A[固定图文件与来源] --> B[核验受控引用] --> C[选择图档位] --> D[展示已生成页面]
```

### 2.3 业务状态机

本章无独立业务状态；一次写出成功才发布，失败不留半份页。

### 2.4 状态值说明

成功记录包含两档成员、节点数、默认档位与真实输入来源；生成失败由生产方保留旧完整结果及真实原因，消费方不展示半份新结果。

### 2.5 功能点清单

1. 两档官方结构图。

### 2.6 功能点详解

#### 1. 两档官方结构图

保留阶段主干与阶段压缩块两档及按宽度适配的初始视口。展示层只切换固定引用；重新生成由 application 显式发起。原 Vis 活网络生成接口已移除，调用方改用 application 的两档操作或 core 通用跟踪能力；历史固定 HTML 不改写。
