## 一、显示资产

### 1.1 背景与定位
大数组不适合通过文本响应传输；显示数据需要保留类型、来源和实体归属。

### 1.2 核心业务操作流程图
```mermaid
flowchart LR
 A[过滤结果] --> B[几何字段分离] --> C[二进制写出] --> D[完整清单提交]
```

### 1.3 业务状态机
转换结果完成后才发布清单，写入失败不能宣称完整成功。

### 1.4 状态值说明
显示数组独立于原始资产；派生身份和原实体映射分别描述。

### 1.5 功能点清单
1. 类型化数组。
2. 显示边界。

### 1.6 功能点详解


#### 1. 类型化数组
几何、拓扑、字段与有效掩码分离。清单记录类型、长度和摘要，浏览器可按需读取。无效值不计入有效范围。
#### 2. 显示边界
单次结果超预算明确拒绝，不自动抽样。原文件不修改，显示结果携带源修订和过滤参数。

坐标空间声明为可选交付。普通 VTK 读取实际 FieldData `coordinate_space_id` / `coordinate_space_unit`；张量点云只读取服务已校验 sidecar 后传入的声明。两者均输出 `coordinate_space={id,unit,evidence:'source-declaration',source_refs:[固定源]}`。缺失时不猜；不完整或非法声明拒绝，不将物理场的 Pa 等单位填为坐标单位。
