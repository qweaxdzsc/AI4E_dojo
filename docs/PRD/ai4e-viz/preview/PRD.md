## 一、文件预览

### 1.1 背景与定位

为本机研究工作流提供文件预览。复用已有案例和任务事实，不增加算法、任务调度、报告发布或多用户权限。

### 1.2 核心业务操作流程图

```mermaid

  A[选择研究对象] --> B[核对范围和输入] --> C[执行请求] --> D[返回真实记录或明确错误]
```

### 1.3 业务状态机

本章无独立业务状态；运行状态由任务管理拥有，检查和预览为一次请求的结果。

### 1.4 状态值说明

成功返回当前记录，失败说明输入、范围或读取原因；连接中断不表示运行失败。

### 1.5 功能点清单

1. 文本与张量。
2. 三维表达。

### 1.6 功能点详解

#### 1. 文本与张量

文本按行翻页，张量按首维翻页并显示完整形状，宽数组限制列数；PT 只读取张量载荷；HDF5 只读取所选数据集，多样本组默认第一份样本。 已有案例和数据格式保持兼容，未支持请求不得静默转换。

#### 2. 三维表达

显示实际表面三角形和点云，点场渐变、单元场平涂，向量用模长着色。大网格明确提示限制，不进行物理算法或插值。 已有案例和数据格式保持兼容，未支持请求不得静默转换。

更新：张量支持指定行列轴和其他维度索引，PT/NPY/Zarr 成员均可分页；大整数显示保持精度。字段摘要由完整实际字段计算并注明范围，不允许作为用户手工归一化输入。三维显示输出已拆为二进制资产；原有基础预览请求保留兼容。

查看器的点字段使用点拾取，单元字段使用单元拾取，读回对应实体的实际分量值；64 位身份按字符串显示。一个窗口的显示预算或渲染错误只影响该窗口。WebGL 上下文丢失时显示等待恢复状态；浏览器恢复后重建渲染对象并恢复相机和字段，不重新提交研究运行。单窗口显示数组预算 128 MiB，共享 CPU 缓冲预算 256 MiB；这些门禁不代表已完成生产规模显存压力验收。

服务可以共享相同源修订与过滤参数的转换；查看器记录初次提交返回的 `subscription_id`，关闭/取消时仅释放该订阅，不能根据共享状态快照获取或猜测其他消费者身份。无订阅字段的旧服务仍使用原无正文取消方式；显式停止整个操作属于服务操作入口，不由普通查看器关闭触发。

相机同源按 project/asset/revision/member/block 完整核对。跨源只接受显示资产中的显式同坐标空间 ID 和坐标单位，且声明绑定本次固定来源；物理场单位或相同外观不作为证据。恢复场景时等待实际显示资产，重新校验相机联动，失败则禁用并显示原因，随后保存不再保留失效联动。

取消发生在提交回执到达前时，客户端仍接收已发出提交的回执，获得订阅身份后再释放，避免服务已创建订阅而浏览器丢失身份。提交前即已取消的调用不会发出请求。状态轮询响应取消，成功缓存既可由提交直接返回，也可由查询返回。
