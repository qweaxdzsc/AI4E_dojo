## 一、科学图像表达

### 1.1 背景与定位

为研究人员表达已经计算完成的物理比较结果。仅依赖稳定产物与渲染库，不调用模型或训练器，不实现物理误差和切面计算，不扩展 Web 平台。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
  A[读取成功比较结果] --> B[校验字段与图形]
  B --> C[生成图像]
  C --> D[组合离线报告]
```

### 1.3 业务状态机

本章无独立持久业务状态，调用失败向调用方传播，比较进度由计算阶段记录。

### 1.4 状态值说明

本章无业务状态值，不把渲染成功当作训练成功。

### 1.5 功能点清单

1. 共色标表面与切片
2. 截面曲线

### 1.6 功能点详解

#### 1. 共色标表面与切片

读取已计算的 VTP 字段，真值和两个模型预测共用几何、视角与色标，两个绝对误差共用独立色标。空场与非有限值拒绝渲染。不在渲染器内预测或切割网格。

#### 2. 截面曲线

按已有连接关系绘制截面曲线，不按 X 排序跨越不同分支连线。显示真实物理坐标和明确的截面比例。
