## 一、可复制普通代理流程

### 1.1 背景与定位

这组模板支持 NASA CRM 工况到全局响应，以及 DoubleCylinder 历史到未来场的 POD 代理。研究正文显式连接普通拟合、可重建状态和固定结果，不将传统代理强制改造成神经训练过程。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
  nasa[NASA属性或已有时间准备] --> preparation[训练独立统计与可选POD]
  preparation --> fit[显式拟合函数]
  fit --> state[保存状态和语义身份]
  state --> check[核对后显式重建]
  check --> infer[预测与物理恢复]
  infer --> post[独立固定结果评价]
```

### 1.3 业务状态机

本章无业务状态。阶段的执行、失败和运行记录由既有运行会话管理；这里描述数据和能力的显式连接，不新增任务状态机。

### 1.4 状态值说明

本章无业务状态值。准备、模型状态和固定结果是独立交接产物，不能把文件存在当作研究验收完成。

### 1.5 功能点清单

1. NASA 与双圆柱两种准备入口
2. 拟合、状态保存与相容推理
3. 普通函数扩展与可选引擎
4. 独立固定结果与不确定性
5. 累计预算与当前交付范围

### 1.6 功能点详解

#### 1. NASA 与双圆柱两种准备入口

NASA CRM 默认二次响应面，直接从训练和测试 HDF5 属性准备全局工况表；DoubleCylinder 默认 POD-RBF，直接消费已有经典时间准备并一次拟合训练降维表示。两例依次执行训练准备、拟合、推理和后处理，不加入无实际作用的原始处理阶段。双圆柱的 POD 拟合属于准备成本，计入同一组合预算。

#### 2. 拟合、状态保存与相容推理

拟合阶段读取归一化特征和目标，调用显式拟合函数，再保存普通状态、诊断及准备身份。推理在重建前核对准备与全部子清单、固定 POD、字段、单位、统计和组件声明；不可因维度相同静默混用。准备和状态可分别整体搬移，自包含内容身份保持一致。NASA 预测恢复系数量纲，双圆柱预测使用冻结 POD 解码并恢复物理场。

#### 3. 普通函数扩展与可选引擎

通过 components.fit 和 components.rebuild 指定全限定普通函数，自定义模型族使用 custom，参数由实际函数解释。拟合函数返回模型、普通状态及诊断，状态由显式重建函数解释；返回模型实例不直接序列化。可选 LightGBM 使用官方引擎和原生模型文本，只有选用时才要求后端。POD 系数预测可以替换为前馈网络而保留相同准备与解码连接，不能宣称更换预测器后仍兼容旧状态。

#### 4. 独立固定结果与不确定性

后处理仅消费已保存物理预测、目标、实体、有效域和时间，原数据或模型不可用时不回退重跑。Kriging 在 NASA 保存恢复物理尺度的 latent 方差，在 POD 保存系数 latent 方差；元数据明确平方单位或系数轴，不声称联合物理协方差。错误语义或非有限输出失败，不发布完整成功结果。

#### 5. 累计预算与当前交付范围

一次代数求解不提供伪造的 epoch 或优化器恢复；重新拟合产生独立状态。阶段内协作截止配合主控进程硬时限，准备、独立参考、重试、恢复和安装核对共同受每组合三小时累计预算约束。本轮源码及合成数据复制流程已有检查，真实数据统一矩阵、安装和 Task 交接继续等待专项证据，不据此声称生产精度。
