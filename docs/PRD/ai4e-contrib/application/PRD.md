### 1.6 功能点详解

#### 1. 数据结构描述

NASA CRM 适配解释 HDF5 点字段、六维工况、全局参考系数和邻接表，交付兼容原有 NPY 分块的数据视图。不同源文件可以重复 Sample 编号，身份以来源和分片区分；同一训练来源的训练与验证不得重叠。

源 manifest 描述版本、文件布局、字段归属与分量、未知单位和官方分片。ShapeNet 官方 train/test 名单与参考统计独立随包发布，默认不会把参考统计当作本次拟合。

#### 2. 数据集选择与复用

共享组件加载器解析数据、模型及业务装配的全限定路径。NASA 采用独立测试来源和固定种子划分，未声明组件的汽车配置自动选择原组件，公开旧键迁移另行处理。数据读取不要求使用者解析具体清单文件映射。

用户选择全部或显式样本列表，选择官方或自定义分片。重复、跨分片重复、越界和不存在的样本拒绝。打开时只访问元数据与路径，不读网格。用户可在任意目录复制 manifest/adapter，通过普通 import 使用；相对资源按 manifest 位置解析。
