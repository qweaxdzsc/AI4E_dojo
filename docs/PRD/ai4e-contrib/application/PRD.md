## 一、共享数据集适配

### 1.1 背景与定位

经典网络的来源与局部模型连接已形成源码，覆盖二维静态场、三维有效域流场及真实时间窗口，功能见第八章。当前真实训练、安装与完整研究流程仍待统一验收，网页模型选项未随此扩展开放。

共享数据集实现可安装、可引用、可复制修改。这里解释特有布局、字段语义和模型/步骤连接；不复制 core 数值算法，不承担平台上传。能力归属默认进入 core，contrib application 只绑定不能中立化的数据、模型参数和业务流程。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
 A[结构描述] --> B[选择样本与分片]
 B --> C[验证样本身份]
 C --> D[返回按需数据集]
```

### 1.3 业务状态机

读取适配器无业务状态。独立生成依次进入 generating，再进入 complete 或 failed；失败不发布完整数据清单。

### 1.4 状态值说明

generating 表示逐样本产生与保存；complete 表示全部数据和清单已发布；failed 表示生成中断，保留已提交记录但不可冒充完整数据集。

### 1.5 功能点清单

1. 数据结构描述
2. 数据集选择与复用
3. 独立生成参数化物理数据

4. 数据集原始处理声明

### 1.6 功能点详解

#### 1. 数据结构描述

领域应用提供可序列化的任务输入需求、执行身份、结果字段和数据清单成员。外流和控制轨迹使用同一套任务管理代码；训练、校准、测试及后训练用途由实际生产步骤标记。标签只能说明候选可选，不能替代内容适用性检查。

官方旧配置加载适配在托管请求内单独校验并行线程和多格式参数，避免将旧加载器不能识别的键写回冻结脚本；多格式恢复到本次公开配置，并行参数只交给样本循环。共享名称由用户明确提供，不从模型或任务名称推断。

新 recipe 显式加载数据与模型组件；模型公开准备、构造、目标与预测接口保留当前语义，旧工作流加载仅作兼容。真实扩展使用普通函数和可重建来源声明；五例允许数据读取与模型完整预测的局部差异。

数据集为推理输出提供真实物理量名称、分量及单位描述：ShapeNet-Car压力和速度的未知单位保持未知；NASA的Cp/Cf为无量纲。物理描述不增加模型未输出的热或结构能力，域和实体归属由实际数据契约确定。

NASA 数据适配提供直接 HDF5 到物理 PT 的字段映射；汽车通过逻辑布局打开原 PT，不改写旧数值。拓扑来源由数据组件解释，模型选择不影响数据身份；NASA 没有体场，不生成体积案例。

NASA CRM 适配解释 HDF5 点字段、六维工况、全局参考系数和邻接表，交付兼容原有 NPY 分块的数据视图。不同源文件可以重复 Sample 编号，身份以来源和分片区分；同一训练来源的训练与验证不得重叠。

源 manifest 描述版本、文件布局、字段归属与分量、未知单位和官方分片。处理描述把各域来源文件名写入 `source_files` 并补到对应输出，页面编辑提取时回填默认 VTK。ShapeNet 官方 train/test 名单与参考统计独立随包发布，默认不会把参考统计当作本次拟合。

#### 2. 数据集选择与复用

WDNO 原版来源审计和缩小训练记录独立保留；当前可安装数据适配、模型连接与可复制研究入口见第四章。基础预测迁移按用户明确授权的缩小范围验收，论文复现与其他任务仍单独限定。

新模型的数据准入与正式适配分开。SafeDiffCon 当前已提供仓库辅助工具核验 Burgers/HDF5 和
Tokamak/Arrow（含压缩分片），记录全部样本的有限性、官方划分、来源摘要及目标语义差异；
本包已新增 SafeDiffCon 数据适配和限时训练连接，见第三章。数据通过不等于原版论文复现通过，
也不会自动注册模型、发布平台数据或改变现有准备记录；原版完整复现后才进入正式迁移。

共享配置转换和模型专属参数解释放在贡献侧连接。复制研究脚本可保留本地扩展参数声明，不需要每次平台内部调整都复制新的转换实现。PDE 模型只提供本流程实际需要的准备参数，不承担外流模型或页面描述约定。外流 `operations.inspect` 对现行公共输入做绑定后检查，并把检查期间的临时数据目录分配到独立检查区，避免案例相对输出落入复制 recipe；任务配置仍含已迁移旧键时明确拒绝；旧采样配置可经显式转换得到副本，检查不改写 YAML。

模型结构检查由应用解析配置、准备真实输入、构造网络并设置两档显示参数，然后调用 core 的通用跟踪能力。AB-UPT 阶段盒按该模型的实际结构组织；普通网络直接交给通用跟踪，不猜模型属性。应用只向管理层返回固定 HTML、参数数量、输入来源和成功失败，网络对象留在应用内部；Vis 与 Task 不再承担活网络出图。旧 Vis 活网络公开入口在仓库调用方全部迁移，历史已生成图仍可展示。

应用负责明确准备、训练与推理的科学连接，可选拓扑只派生图缓存。动态导入模块及必要资源由应用声明 SOURCE_DEPENDENCIES，管理层记录来源而不解释模型参数；静态可发现依赖不重复声明。

Transolver 的参考选优切片接受现行 `eval` 与旧名 `validation`，两者表示同一评价切片；平台能力使用现行名称。该别名转换不改变样本集合、精度类型、优化器或指标，不改写历史准备。

共享组件加载器解析数据、模型及业务装配的全限定路径。NASA 采用独立测试来源和固定种子划分，未声明组件的汽车配置自动选择原组件，公开旧键迁移另行处理。数据读取不要求使用者解析具体清单文件映射。

用户选择全部或显式样本列表，选择官方、`unsplit` 或自定义分片。`unsplit` 仍核验官方名单人数，但把全部样本收成单一训练宇宙，供平台原始处理不按 train/test 落盘。重复、跨分片重复、越界和不存在的样本拒绝。打开时只访问元数据与路径，不读网格。用户可在任意目录复制 manifest/adapter，通过普通 import 使用；相对资源按 manifest 位置解析。



平台检查入口 `inspect_dataset(config)` 提供来源、稳定样本身份、分片、完整依赖和真实字段目录。带 `sample_scope` 时输入宇宙是数据集官方或自身分片，不吃任务里的子集声明，并回传 `sample_universe`。汽车按样本目录校验选定域文件并读取真实 VTK 点/单元数组；NASA 将 HDF5 文件与文件内样本分开，校验连接关系依赖，允许显式读取原始数值点字段。未知单位保持空值，不能将同名数组视为相同物理量。

#### 3. 独立生成参数化物理数据

最小验证数据由案例资源清单显式选择生成入口与预算；任务管理只在隔离进程调用该入口，不导入或推断参数化方程。

对流扩散、Neumann 扩散、Advection、Burgers 和梯形域扩散各有独立生成入口。用户先产生新数据集，再执行准备和训练；生成过程不依赖模型。
数据保存实例参数、物理/参考轴、参考场、映射与身份。Neumann/Advection保留原连续MT19937训练后测试抽样，轴、标签及参数保存为原FP32精度；Neumann在FP32坐标上计算解析标签，Advection保留显式取模后转FP32。其他未迁移生成器仍使用分离随机流；梯形保留原连续随机流，训练后消耗一个原演示实例，再产生十个测试参数，记录明确名单。
已有非空输出目录拒绝写入；逐样本原子提交，全部成功后才发布完整清单。部分失败保留已生成记录，不冒充可训练的完整数据集。
对流扩散采用与积分等价的闭式概率，Burgers使用不重复端点的周期FFT网格。梯形使用用户选定的源码近似差分及Euler：默认十个训练实例、21×21空间点、1001时间片，逐步保存单精度场；中间计算保留原标量精度。稳定条件不满足则失败，不自动加子步。此标签是近似数值参考，不是完整坐标变换的解析真值。
数据变更产生新版本并记录数值协议。旧完整映射梯形数据及旧随机流/精度的Neumann、Advection数据不可作为选定实验的输入；不覆盖历史数据，失败不发布完整清单。

#### 4. 数据集原始处理声明

- ShapeNet-Car 与 NASA 的默认处理参数及可选输出随数据集声明提供，未绑定来源也可展示。两份清单默认写出 `formats: [pt]`，不再用旧单键 `format`；与平台选项合并时以页面值为准，不报冲突。两类来源只要提供真实网格或 connectivity，均声明 VTKHDF 能力并默认打开；NASA 使用官方 connectivity 和每个样本坐标交付表面网格。绑定后读取各分片代表样本的真实字段，执行前覆盖选定样本检查。完整范围来自数据集声明名单，不递归处理名单外目录；缺失不自动补齐。NASA 的共享文件与文件内样本独立。ShapeNet 最近顶点距离与体积法向是两项独立几何能力；`volume_normals` 不再挂在 `nearest_vertex` 下。历史任务若已保存体积法向且启用了最近顶点，解析时提升为独立能力。


## 二、GenCP 数据与案例连接

### 2.1 背景与定位

将发布数据原生数组接入耦合领域，数据无需转换为 VTK。保留官方分片，重叠窗口按需读取。

### 2.2 核心业务操作流程图

```mermaid
flowchart LR
  N0["三套数据来源"] --> N1["案例配置和模型连接"]
  N1["案例配置和模型连接"] --> N2["单场验证与物理恢复"]
```

### 2.3 业务状态机

本章无业务状态；普通能力由调用方组合，失败以异常交接。

### 2.4 状态值说明

本章无业务状态，不建立共享全局生命周期。

### 2.5 功能点清单

1. 三套数据来源。
2. 案例配置和模型连接。
3. 单场验证与物理恢复。

### 2.6 功能点详解

#### 1. 三套数据来源

两个 FSI 分支分别验证九个训练和一个验证文件，原裁剪、历史与预测窗口固定；HDF5 中的实际网格与物理时间可从冻结来源读取，结果保存坐标与时间值，未声明的单位不猜测。核热以发布 NPY 行配对三个异形网格，训练与耦合分片独立。

#### 2. 案例配置和模型连接

模型参数、目标、归一化和原始字段解释归贡献连接；核心领域不认识具体网络。完整导入路径可换用户条件和构造器，路径按配置文件解析。

#### 3. 单场验证与物理恢复

连接原单场生成能力、验证样本及物理指标。FSI 流体按 u、结构按 SDF 选优；核热流体各分量相对误差平均。耦合最终结果另行评价。

## 三、SafeDiffCon 数据与案例连接

### 3.1 背景与定位

绑定原始两个数据集、原生通道和领域步骤，扩展研究无需改平台或框架注册表。

### 3.2 核心业务操作流程图

```mermaid
flowchart LR
  A[明确输入和预算] --> B[执行所选步骤]
  B --> C[保存带来源的产物]
  C --> D[独立读回和比较]
```

### 3.3 业务状态机

```mermaid
stateDiagram-v2
  [*] --> 待执行
  待执行 --> 执行中
  执行中 --> 已完成
  执行中 --> 未完成
```

### 3.4 状态值说明

待执行表示仅有参数；执行中表示计算尚未交付；已完成要求对应步骤产物完整；预算耗尽、异常和数据不符均为未完成，不能据此宣称论文达标。

### 3.5 功能点清单

1. 官方样本与常数缩放

2. 预训练与两轮后训练

3. 显式适配与严格配置


### 3.6 功能点详解


#### 1. 官方样本与常数缩放

Burgers固定39000/1000/50；Tokamak固定48950/1000/50。Arrow可从现有ZIP流读取；不重划测试集。Burgers补齐到16并除10，Tokamak补齐到128并按12通道常数缩放。原outputs目标与数据targets独立保留。


#### 2. 预训练与两轮后训练

原Adam预训练参数、余弦调度和EMA保持；批次流可恢复并保留尾批。两轮开始校准、明确交接后训练权重，属于已披露的原脚本顺序修正；不通过继续错误长训练获取新基线。

预训练更新数表示含恢复历史的总目标，默认4000，当前短实验允许1至20000的整数；这只是规模检查，不代表这些步数必然能在三小时内完成。继续训练须使用相容的准备、模型、学习率、批量与随机种子，保留原调度位置，不把目标步数当作额外增加量。实际执行仍由原累计账本监督，预留最终响应评价时间后冻结步数。历史4000步配置及准备记录继续有效，不更改冻结摘要。


#### 3. 显式适配与严格配置

适配次数表示实际参数更新次数；读取明确准备和检查点。配置、覆盖和程序入口检查相同参数，未知键拒绝，相对路径按配置文件展开。安全引导、目标、模型、变换和派生量可通过普通函数路径替换。

公共用户输入按阶段分组，领域内部参数只在实际调用前绑定，不回写用户配置。求解器资源作为推理输入捕获，解释器位置保留虚拟环境身份；不追随解释器符号链接到缺依赖的基础环境。旧配置显式转换生成新副本、路径以旧目录为基准，新旧键混用拒绝；已有数组与完整训练状态按原科学合同继续消费。固定结果按完整自包含目录登记，后处理只消费已保存数组。预训练、后训练和适配权重补充阶段身份；指标包含固定真值、样本与统计定义，不能因缺语义冒充可比较结果。

### 5.6 功能点详解

#### 1. 官方数据字段和分片适配

读取 train、valid、test 分片，以 meta.json 解码 cells、mesh_pos、node_type、velocity
和可选 pressure。首期只消费二维速度；静态字段保持一份，不人为复制到每个时间步。
固定网格轨迹至少有三个帧，拓扑和节点身份在整条轨迹内保持不变。

#### 2. 训练帧与节点语义

训练从完整轨迹的中间帧取当前速度和后一帧目标。九类节点以 one-hot 加到速度后；
只有 NORMAL 节点加噪，NORMAL 和 OUTFLOW 节点进入损失。其他类别作为边界，在 rollout
中保持初始速度。类别越界或局部索引越界时拒绝。

#### 3. 模型归一化、目标和恢复连接

完整十一维节点特征、三维边特征和二维速度增量分别在线累计统计。噪声加入输入后从
速度增量目标扣除；损失在两个速度分量上求和，再对选中节点平均。检查点身份包含网络
结构、batch、噪声、预热和学习率协议，缺失或不一致时不能继续训练。

#### 4. rollout 与论文指标连接

模型输出经反归一化后作为速度增量积分。固定结果按样本保存不同节点数的轨迹，并报告
1、10、20、50、100、200 步可用 horizon 的累计 MSE；初始帧排除，轨迹之间等权。
这些名称对齐评价程序，但只有同数据、同预算的实跑才能形成论文复现结论。

#### 5. 静态外流字段与分区连接

ShapeNet-Car 把位置、法向和距离绑定到表面/体积两个独立网络，分别预测压力和三分量
速度；NASA CRM 把六维工况广播到表面节点并预测 Cp 与三分量 Cf。训练只在核心节点
计算监督，halo 只提供 Processor 消息上下文；推理要求核心块互斥且覆盖完整原点身份。
两例沿用外流物理指标，仅证明工程连接，不形成 MeshGraphNets 论文复现结论。

### 8.6 功能点详解

#### 1. 三类物理来源与监督身份

Darcy按已声明的训练与测试来源选择固定数量，坐标、系数和解使用同一原网格索引；默认步长5得到保留边界的85×85规则场，输入为二维坐标和系数，目标为解。ShapeNet-Car按官方名单选择样本，输入为三维坐标、仅由表面几何产生的无符号距离及有效标记，目标为体速度三个分量。距离先在来源体顶点求得，再插值到规则格，是线性插值近似，不是每个规则格点的精确最近面距离。默认32³规则格由真实体单元插值产生，无支撑位置保留占位零及独立mask；回贴只接受完整有效单元的支撑，不承诺原点全覆盖。

双圆柱从训练和验证来源选择轨迹，默认两条训练和一条评价轨迹。每个窗口保留四个来源时刻，前三个作为历史、第四个为目标，间隔10个来源时间索引；网格为128×128。来源时间、坐标或窗口形状不符时拒绝，不把静态样本序号或空间点当成时间。四个发布物理分量及已有压力缩放语义保持显式，原始来源不回写。

#### 2. 共享准备与训练统计

准备保存物理输入、物理目标、归一化值、有效域和实体身份；时间案例另保存时间。统计只使用所选训练分片及有效域，测试不参与拟合；ShapeNet有效标记本身不标准化。准备不含模型私有拓扑或权重结构，因此同一数据绑定下可供多个结构使用。

清单用相对引用保存已物化数组，读回检查版本与受控范围，不能靠原源目录存在来补齐缺失数组。ShapeNet准备包含自有物理快照，用于按原点身份回贴，整体搬移时一同携带。改变格点规格、来源分片或时间窗口须重做对应准备并明确新研究身份；历史冻结记录不自动迁移或改写。

#### 3. 经典模型及用户组件连接

局部模型选择将完整核心模型或普通用户构造器接入训练。静态规则场使用末轴通道保存，卷积族显式转为通道在前，注意力接收独立有效标记；图网络从规则格及有效节点生成有向连接，输出回贴同一格点身份。基础循环网络将每个空间点的真实时间历史组织为独立序列，使用末时刻预测，不跨窗口持有隐式隐藏状态。

自定义构造器接收本案例模型配置并返回普通网络；选择custom时直接接收本地连接的原始布局。空间循环组合必须保留完整历史网格，不能沿用点采样后的输入。网络专属形状转换由局部连接承担，不修改通用运行器或要求用户继承新协议。

#### 4. 固定结果与派生数组消费

固定权重预测经训练统计反变换后，与物理真值、实体和有效标记共同保存。派生函数返回新增数组及单位、实体、mask声明，名称不能覆盖已有输出；独立后处理读回并在有效域按样本及物理分量评价。零真值范数的相对误差保留不可计算含义，不填造正常相对误差。三维覆盖、投影误差和模型误差应分列，不把无支撑占位零纳入准确率结论。ShapeNet固定结果另保存按原点顺序拼接的预测、真值、坐标、实体及有效标记，以样本偏移界定各例；后处理可仅凭固定数组报告原网格支撑域误差与覆盖率。

派生消费者只读取固定结果，不重跑模型。通用末轴范数示例在没有共同单位声明时保留unknown；混合物理分量范数不能解释为速度。字段语义变化由用户显式改写派生函数与声明，保存读回的成功不等于科学量定义正确。

#### 5. 局部配置与兼容边界

配置显式声明数据案例、通道、空间维度、构造器、阶段外部输入及输出根；非法计数、维度或本批不支持的取批选择明确失败。当前对照固定批量1，基础RNN仅绑定真实时间案例，custom构造器保留局部扩展空间。每次训练有局部时限，组合累计三小时预算仍由主控外部账本统一管理，不能为参考、重试或恢复分别重置。

训练沿用共享更新和检查点恢复。模型结构或训练统计不相容时不可静默部分加载；同一配置形状并不保证任意用户实现可以互换。新增入口不会自动登记到网页模型选择，既有外流、谱模型与历史记录保持原适用范围。

### 9.6 功能点详解

#### 1. 三类已有场准备的复用

Darcy 与 ShapeNet-Car 保持既有来源、训练分片统计、实体和有效域；ShapeNet 仍保存原网格身份与可回贴物理快照，插值覆盖和模型误差分别报告。DoubleCylinder 保留真实三帧历史与下一帧目标，不把空间点轴当时间。准备与完整场布局必须一致；现有物理数据及冻结记录不被批量改写。

#### 2. 传感器、查询与历史通道连接

DeepONet 从每个样本的规则格按声明步长取固定传感器，查询坐标与输出网格逐样本对齐，多分量采用明确分支分组。FNO 消费完整二维或三维场；DoubleCylinder 按固定时间先后将三帧历史合并到输入通道，输出下一帧。本批时间案例只开放 FNO 连接，不能仅切换名称假定 DeepONet 已适配。模型构造器可由全限定普通函数替换；局部连接仍检查网格及输出语义。

#### 3. 监督与经准入的物理目标

默认仅使用有效域监督。Darcy 可以显式启用非负解违约惩罚，来源已确认的正系数、非负源和零 Dirichlet 条件支持最大值原理；该项复用现有残差损失并在恢复物理尺度后计算。离散采样外圈未必是精确边界，不能对该圈强加零值；该项也不等于完整 PDE 残差，不是新增 PINN 架构。其他案例启用此物理权重明确拒绝，训练前后的物理目标影响须分别核实。

#### 4. 共享训练、固定预测和配置边界

训练复用公共监督更新和完整状态恢复；推理按相容配置恢复权重，再保留物理字段、有效域及实体身份。后处理只读取固定结果，来源或模型不可用时也不重跑预测。本批算子消费完整规则场，拒绝沿空间点随机切块；非法网格、物理权重和家族连接在局部配置或实际消费处失败。每个实际组合的准备、参考、重试及恢复累计上限三小时，由主控串行账本监督。

### 10.6 功能点详解

#### 1. NASA 全局响应表

从分别指定的 NASA CRM 训练与测试来源读取六个工况属性，预测阻力、升力及俯仰力矩三个无量纲系数。相同 Sample 名称保留来源和分片身份，训练与测试不能使用同一文件，也拒绝复制或改名后跨分片重复的完整工况响应记录；相同工况但不同响应保留并单独诊断，不能仅依文件路径声称来源独立。训练独立拟合输入及目标统计，验证数据不参与；该产物明确是全局属性表，不作为缺少网格的场预测或平台物理准备。二次响应面需要足够且满秩的训练设计矩阵。

#### 2. DoubleCylinder 训练独立降维

消费既有时间准备，检查训练与验证轨迹分离、窗口时间身份、完整共同有效网格及原实体顺序。历史与未来统一使用训练 target 通道统计，按轨迹和时间去重训练快照，仅拟合一次 POD；重复身份内容不同明确失败。默认秩二，可显式选择秩三；保存固定基、场布局和训练身份。历史三帧系数作为特征，下一帧系数作为目标，历史特征统计仅拟合训练窗口。当前尾项需要可识别且有剩余样本，秩或窗口不足不自动降级。

#### 3. 普通拟合函数与显式重建

默认连接响应面、三次核 RBF、独立目标 Kriging 和官方 LightGBM 后端。拟合返回普通状态及诊断，不 pickle 模型对象；自定义拟合和重建函数通过完整导入路径选择，状态格式可以由用户本地解释，不要求修改框架注册表。代数一次求解没有伪造 epoch 或优化器恢复；追加树模型轮次与神经训练恢复语义分别说明。

#### 4. 严格语义核对与固定预测

模型状态保存准备顶层及子清单内容身份、POD 状态身份、字段、单位、统计、模型和组件声明。推理先核对这些约定再重建，维度一致不能绕过语义冲突；整目录移动不改变内容身份。NASA 输出恢复三个物理响应，POD 使用同一次冻结基重建物理场，再携带目标、时间和实体保存。独立后处理只读固定结果并按样本与分量评价，无需原数据、准备或模型。

#### 5. 方差交付与使用范围

独立目标 Kriging 可保存 latent 边际方差。NASA 方差按目标尺度的平方恢复，与物理目标同形，单位明确为平方；POD 仅保存每个系数的 latent 方差及轴说明，不能解释为联合物理场协方差。均值评价保持既有口径，不因方差数组增加而改变；模型误差、降维重建误差和不确定性分别表达。
