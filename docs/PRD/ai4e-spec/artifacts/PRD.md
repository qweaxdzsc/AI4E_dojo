## 一、运行来源

### 1.1 背景与定位

让任务和计算入口共享稳定运行身份，产物脱离管理数据库后仍能说明来源。不承载训练对象或管理事务。

### 1.3 业务状态机

本章无业务状态；契约为一次运行的不可变传递对象。

### 1.4 状态值说明

本章无业务状态；未知契约版本或空身份被拒绝。

### 1.5 功能点清单

1. 传递运行身份和完整来源
2. 独立保存和版本校验
3. 固定文件与显示来源
4. 区分研究运行和辅助操作

### 1.6 功能点详解

#### 1. 传递运行身份和完整来源

新增独立预览请求与结果描述。只描述检查和显示，不增加处理方案或张量交付协议。

携带项目、任务、正式版本、运行标识及代码、数据、运行位置，保留版本创建记录、输入资产和恢复来源。运行身份不改变正式版本身份。

#### 2. 独立保存和版本校验

物理预测清单交付具名域、字段文件映射、点身份基础与来源协议。比较图形引用交付已计算几何、字段、物理切面坐标和显示方向；可视包按这些稳定事实表达，不需要读取训练对象。

显示清单可带 `coordinate_space`：源声明的空间身份、坐标单位、`source-declaration` 证据类型和固定资产引用。未知时省略，不以物理场单位填充。跨源相机联动必须验证该证据；保存场景重新加载时再次验证。旧清单仍能独立显示和同固定源联动。

只使用轻量可序列化值。接收方核对契约版本与身份；计算入口将记录写入自包含运行目录，旧独立调用无需提供此契约。

#### 3. 固定文件与显示来源

文件引用包含项目、资产和内容修订，文件成员与多块成员可独立定位。浏览器传递身份，服务校验实际可访问位置；旧修订不能代表修改后的内容。字段身份区分几何、点、单元与文件成员，同名字段不合并，未知单位不猜测。

显示清单保留源引用、几何、拓扑、字段、有效性和实体映射。数组独立传递，原始身份与过滤生成实体分别说明，避免用显示顶点编号误认物理实体。场景只保存可恢复描述，并固定源修订；不保存运行时显存对象。

#### 4. 区分研究运行和辅助操作

检查和显示转换传递辅助操作进度与终态，研究运行保留原有 task 身份。进度允许未知，断线不代表失败。取消、失败、源内容失效与重启中断分别表达；已完成操作不能被迟到事件改回运行中。跨语言消费者由同一稳定声明生成类型，旧预览描述在迁移期间保持兼容。
