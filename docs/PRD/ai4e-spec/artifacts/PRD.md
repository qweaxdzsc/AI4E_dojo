## 一、运行来源

### 1.1 背景与定位

让任务和计算入口共享稳定运行身份，产物脱离管理数据库后仍能说明来源。不承载训练对象或管理事务。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
  A[任务分配身份与位置] --> B[校验契约版本] --> C[计算入口保存来源]
```

### 1.3 业务状态机

本章无业务状态；契约为一次运行的不可变传递对象。

### 1.4 状态值说明

本章无业务状态；未知契约版本或空身份被拒绝。

### 1.5 功能点清单

1. 传递运行身份和完整来源
2. 独立保存和版本校验
3. 固定文件与显示来源
4. 区分研究运行和辅助操作

5. 声明驱动的原始处理交接

### 1.6 功能点详解

#### 1. 传递运行身份和完整来源

新增独立预览请求与结果描述。只描述检查和显示，不增加处理方案或张量交付协议。

携带项目、任务、正式版本、运行标识及代码、数据、运行位置，保留版本创建记录、输入资产和恢复来源。运行身份不改变正式版本身份。

#### 2. 独立保存和版本校验

物理预测清单交付具名域、字段文件映射、点身份基础与来源协议。比较图形引用交付已计算几何、字段、物理切面坐标和显示方向；可视包按这些稳定事实表达，不需要读取训练对象。

显示清单可带 `coordinate_space`：源声明的空间身份、坐标单位、`source-declaration` 证据类型和固定资产引用。未知时省略，不以物理场单位填充。跨源相机联动必须验证该证据；保存场景重新加载时再次验证。旧清单仍能独立显示和同固定源联动。

只使用轻量可序列化值。接收方核对契约版本与身份；计算入口将记录写入自包含运行目录，旧独立调用无需提供此契约。

#### 3. 固定文件与显示来源

文件引用包含项目、资产和内容修订，文件成员与多块成员可独立定位。浏览器传递身份，服务校验实际可访问位置；旧修订不能代表修改后的内容。字段身份区分几何、点、单元与文件成员，同名字段不合并，未知单位不猜测。

显示清单保留源引用、几何、拓扑、字段、有效性和实体映射。数组独立传递，原始身份与过滤生成实体分别说明，避免用显示顶点编号误认物理实体。场景只保存可恢复描述，并固定源修订；不保存运行时显存对象。

#### 4. 区分研究运行和辅助操作

检查和显示转换传递辅助操作进度与终态，研究运行保留原有 task 身份。进度允许未知，断线不代表失败。取消、失败、源内容失效与重启中断分别表达；已完成操作不能被迟到事件改回运行中。跨语言消费者由同一稳定声明生成类型，旧预览描述在迁移期间保持兼容。


#### 5. 声明驱动的原始处理交接

- 处理描述包含数据集身份、绑定方式、默认参数、可选字段及依赖。真实检查另外记录样本身份、检查范围、来源修订和缺失诊断。默认配置不是已检查成功的证据；逐场输出必须保持实体身份与物理状态。

## 项目任务可视化交接

### 2.1 背景与定位

可视化交接区分可信存储上下文、固定输入引用、配置资产引用与显式输出引用。机器目录不进入浏览器类型；导出不会改变配置身份。

### 2.2 核心业务操作流程图

```mermaid
flowchart LR
    A[选择任务与固定来源] --> B[打开可视化工作区]
    B --> C[调整并保存配置]
    C --> D[读取固定修订]
    D --> E[按需显式导出]
```

### 2.3 业务状态机

本章沿用任务归档状态；交互会话与导出状态由独立可视化模块负责，不在本模块复制状态机。

### 2.4 状态值说明

可写任务允许保存和导出；归档任务只允许读取既有配置。数据缺失或修订变化显示错误，不能作为成功重开。

### 2.5 功能点清单

1. 明确任务保存上下文。
2. 固定来源与配置资产交接。
3. 独立工作区与显式输出。

### 2.6 功能点详解

#### 1. 明确任务保存上下文

保存位置属于选定项目任务；不要求迁移原数据，不创建新的研究版本。

#### 2. 固定来源与配置资产交接

只保存引用、处理步骤与显示配置；输入修订和配置修订分别校验。缓存删除不影响读取配置。

#### 3. 独立工作区与显式输出

页面与脚本共享业务入口；图片、视频和提取数据只在明确输出操作时生成。配置保存和导出是两个操作。

## 三、独立推理来源与选择

### 3.1 背景与定位

让界面、脚本、任务管理和结果消费者共享固定推理意图及来源身份。契约只包含可序列化声明，不包含模型、权重数组、浏览器对象或任意服务器输出路径；不执行文件冻结、进程控制或数值兼容算法。

### 3.2 核心业务操作流程图

```mermaid
flowchart LR
  A[声明检查点修订和样本选择] --> B[校验请求形状与参数]
  B --> C[任务核验实际来源并执行]
  C --> D[传递固定批次运行样本身份]
  D --> E[结果消费者解析受控成员]
```

### 3.3 业务状态机

本章无业务状态。请求和结果引用是稳定声明，执行状态由任务与计算报告维护；结构合法不意味着已执行成功。

### 3.4 状态值说明

请求缺少必要身份、修订或样本，含未知参数、重复选择或不支持的输出组合时拒绝。实际来源修订不一致、模型不兼容及文件缺失由使用契约的业务层明确返回，不能以空对象替代有效引用。

### 3.5 功能点清单

1. 声明固定检查点与批次选择
2. 校验输出和设备参数
3. 传递可追溯结果身份

### 3.6 功能点详解

推理选择可包含多个分片的样本身份，旧单分片选择转换为同一内部表达；新旧写法同时出现时拒绝。物理量与指标显式空选择不恢复默认。结果身份增加分片，版本化轻量结果保存逐样本指标、字段、计时、状态与来源；旧结果保持可读，缺少证据不能补造可比性。

#### 1. 声明固定检查点与批次选择

每个检查点包含实际候选身份和内容修订，批次同时声明预期任务配置修订、有序样本名单和分片。检查点、样本不能为空或重复；名称必须有效，幂等身份用于提交重试，不作为科研内容摘要。实际文件和准备兼容仍由业务层核对，不能只凭请求结构判为可执行。

#### 2. 校验输出和设备参数

设备按明确支持的选择表达，自动模式由任务根据实际设备和已知占用解析。预测保存、评价和网格输出分别声明，查询分块为正整数。网格交付依赖已保存预测，不能提交矛盾的输出组合；未声明能力不会由消费者自行猜测开启。

#### 3. 传递可追溯结果身份

结果引用保留任务、批次、运行、检查点修订和样本身份。多个检查点对相同样本的结果因此可区分，后处理不会因新结果写入而漂移到其他运行。具体成员通过固定资产引用读取，数组独立保存；新增结果不新增正式研究版本。旧物理预测清单和历史 post 调用按既有版本分别校验，不把新请求契约强行写回历史文件。
