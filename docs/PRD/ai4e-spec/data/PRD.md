## 一、文件检查描述

### 1.1 背景与定位

为本机研究工作流提供文件检查描述。复用已有案例和任务事实，不增加算法、任务调度、报告发布或多用户权限。

### 1.2 核心业务操作流程图

```mermaid
flowchart LR
  A[选择研究对象] --> B[核对范围和输入] --> C[执行请求] --> D[返回真实记录或明确错误]
```

### 1.3 业务状态机

本章无独立业务状态；运行状态由任务管理拥有，检查和预览为一次请求的结果。

### 1.4 状态值说明

成功返回当前记录，失败说明输入、范围或读取原因；连接中断不表示运行失败。

### 1.5 功能点清单

1. 字段目录。

### 1.6 功能点详解

#### 1. 字段目录

区分坐标、点场、单元场、张量成员和表格列。描述保留名称、实体数、分量与数据类型，不猜物理意义。 已有案例和数据格式保持兼容，未支持请求不得静默转换。
