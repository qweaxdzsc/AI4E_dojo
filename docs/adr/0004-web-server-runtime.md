# ADR 0004：Dojo 本机 Web / Server

日期：2026-09-10。状态：已接受（用户批准的首期实施计划）。

研究人员需要通过页面创建研究任务、编辑既有案例配置并执行。首期采用 React 18、TypeScript 5、Vite 6、Ant Design 5、React Router 6；FastAPI/Pydantic/Uvicorn 提供本机 API。具体补丁版本由 package-lock.json、uv.lock 锁定。Python 保持 3.12，新增包仍为一层物理目录。

task 继续拥有项目、任务、版本、工作目录及运行事实。server 保存项目位置及服务自有场景、比较、辅助操作；不复制 task 管理事实。报告编辑入口暂不开放，保留历史记录。只有 new/fork 创建版本；保存配置核对文件摘要且原子替换。模板默认数据路径可在创建时未绑定，执行仍严格读取实际输入。

服务调用 submit_run，通过固定配置修订、输入资产与 pipeline.stages 执行现有案例。用户批准的并行扩展允许算法侧补齐字段输出、Zarr、Min-Max、模型采样迁移与检查门面；recipe 保持薄配置入口，平台不复制算法。页面编辑唯一任务 YAML，均值、标准差、Min/Max 统计只能读取真实产物，不能手工保存。

部署只监听 127.0.0.1。数据根由启动参数明确登记；生产构建可通过 --web-dist 与 API 同源提供，开发使用 Vite 代理。远程多用户、批量调度和报告编辑不在本期。第 2–7 步接入真实工作流；模型与训练设置页面主要提供配置与检查。新增能力必须通过相关自动化测试和真实四组合交接，不能以技术栈初始化当作功能交付。
