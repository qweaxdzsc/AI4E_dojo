# ADR 0005：独立文件预览与 VTK 转换进程

日期：2026-09-10。状态：已接受；实现与验收进行中。

文件读取与 VTK 过滤可能耗时，服务把受控资产解析为本机路径，在独立 ai4e_viz 进程执行。viz 仅依赖 spec 和第三方读取、可视化库，不导入 core、contrib、recipe 或模型。服务负责操作身份、生命周期、取消、超时、恢复、缓存登记和下载范围；转换进程负责文件读取、数值过滤及结果原子发布。task 仍独占研究运行，两条进程链只共享辅助操作传输约定。

版本 1 使用逐行 JSON 事件，标准输出只承载 progress/result/error，第三方日志进入标准错误。大数组写入独立二进制成员，清单记录类型、形状、字节序、长度和摘要。源内容修订、转换参数、协议版本参与缓存身份。取消或文件改变不得发布成功结果；重启后未完成操作标记 interrupted，不自动重复研究运行。

浏览器采用 vtk.js，显示源、过滤节点、表示、窗口分别建模。服务端 VTK 保留体网格，完成切片、裁切、阈值、点标量等值后才提取显示几何；点场、单元场、原始实体和生成实体分别描述。不得把单元场静默转成点场，身份整数不得经浮点 JSON 丢失精度。二进制几何可在字段切换时复用。

场景保存固定资产修订、管线、属性、窗口及联动组，不保存 WebGL 对象。最多四个活动窗口；相机、字段、色标分别显式启用联动，相机默认关闭。资源按窗口引用释放，迟到的转换结果不能覆盖新选择。显示变换与科学数据计算分开，不自动配准或插值。同身份差值在算法进程完成，viz 仅显示稳定产物。

兼容旧预览请求只用于已有消费者迁移，正式工作区使用版本化进程与资产接口。文件大小、点数、分页、进程时间和内存限制必须显式失败，不使用降采样或示意数据冒充完整结果。实际通过项目及尚未完成项统一记录于 .context/mvp/web-integrated-acceptance.md。
