# 三维物理场可视化 UI 界面说明

本版纳入已确认的对象、着色、布局与动画决策。原「后处理-三维可视化.png」保留作为布局与配色参考；图中物理量和单位只是示意。功能验收状态见仓库上下文中的三维工作台验收记录。

## 1. 界面定位

Trame + VTK 拥有完整三维工作台，可独立运行或嵌入 Dojo。Vis React 承载来源选择、保存、外部配置、动画和输出表单；Dojo 提供项目任务入口及来源授权。嵌入内容不显示重复平台导航。

## 2. 顶部第一行：创建分析对象与时间

没有“云图”创建按钮。矢量图、切面、剖切、流线、等值面、等高线、Probe 使用当前对象为输入，生成各自的参数草稿，应用成功后进入正式场景。

- 矢量图：三分量字段、箭头比例、采样间隔。
- 切面：平面原点、法向。法向是无量纲方向，不能为零。选中后视口出现可视平面，可沿 X/Y/Z 拖动原点、旋转法向，或点属性 X/Y/Z 轴对齐；拖动只预览，仍须应用才切开。
- 剖切：平面原点、法向和保留侧，输出仍可继续分析。选中时同样使用可视平面，不进对象树。
- 流线：矢量字段、起点类型（线段/球体/平面/命名面，一排按钮切换）、数量、积分方向和几何积分长度。新建时起点落在当前对象包围盒内；应用时种子贴到网格上。命名面可选对象树已有表面或网格命名块/文字分区；没有命名面时提示改用几何起点。应用后看得见种子，不能拖、不另建对象。旧流线没有起点类型时仍按线段起终点计算。
- 等值面：体数据上的字段、矢量分量或模长、等值列表。
- 等高线：表面或切面上的字段和等值列表；基础显示上的等高线明确提取表面。
- Probe：固定空间坐标、输入和展示字段；输入坐标或在模型上拾取。

缺少相应字段或拓扑条件时禁用。计算失败保留上一次成功画面；有效计算没有实体时显示“结果为空”。

时间工具提供正放、倒放、暂停、逐帧和实际时间选择；停止回到首帧。静态结果禁用播放。顶部动画默认生成时序 MP4；实际操作录制从导出菜单进入。

## 3. 顶部第二行：即时显示

选择、旋转、平移、缩放、适窗、坐标轴和标准视图操作活动 Render View。着色物理量、point/cell 归属、分量或模长、色带、离散层数、自动或固定范围、图例、透明度、表面/网格/表面加网格和光照操作选中对象在活动视图中的显示实例。

着色与分析参数独立：流线可由速度计算再由压力着色；等值面可由温度提取再由速度模长着色。Rainbow、Jet、Turbo、Cool to Warm 与已有色带并存。阴影只在支持的远程渲染环境开放。未声明的单位不猜测。

## 4. 左上：结果与对象树

导入结果只自动创建纯色「基础显示」，不预建压力、温度等字段节点。树的父子关系表达真实处理依赖，例如「结果 → 基础显示 → 切面 → 等高线」。选中对象后同步属性和工具栏。

眼睛控制活动视图的显隐，结果级眼睛控制其全部对象。行右侧删除图标删除该对象，仍先列出下游依赖并确认。搜索保留匹配对象与祖先，不修改显隐。重命名不改变身份；复制共享输入数据但参数和显示独立。移除结果不删除源文件。

## 5. 左下：单对象属性

属性区比对象树更高、更靠上，框内可滚动到「应用」。显示属性即时生效；计算参数必须点击应用。切换对象保留各自草稿和未应用标记。保存或输出前先应用、丢弃草稿或取消操作。外部配置由文件菜单打开独立对话框，不常驻 JSON 编辑器。拖动切面可视平面只改草稿数字，切开结果停在上一次成功应用。文件预览放大后工作台贴满弹窗，对象树、属性和三维窗口都要露出。

Probe 提供当前数值表格、时间曲线和显式 CSV 输出。方向标记、Probe 标签与时间文字属于真实渲染场景，同时进入截图和动画。

## 6. 中央工作区与多视图

最多四个窗口。新增标签即新增窗口：先一个，再横排两个，第三个出现在下方通栏，第四个为田字格。每个窗体左上角是对应标签，窗体本身为白底加明确边框。支持选择、关闭、分割比例与最大化。新窗口复制活动窗口设置，后续独立编辑；关闭窗口不删除计算对象。

多窗口共享数据与计算结果，各自保存显隐、着色和图例。相机联动默认关闭，开启后全体窗口共用相机；仅允许同一来源或明确同一坐标空间。不自动对齐、跨网格插值。左侧宽度和树/属性分区高度可调整。

## 7. Probe 与时序

Probe 固定在世界坐标，时间变化重新采样，不跟随移动实体。域外、缺帧、字段缺失显示对应状态，不填零。标签显示名称、XYZ 和字段值。多结果按实际时间精确匹配，缺帧明确标识，不暗中插值。拓扑不变时复用几何并保留当前帧数组，拓扑变化重建。

## 8. 保存、重开与配置

物理配置版本 2 分离来源、处理节点、显示实例、Probe、视图、单一布局、联动与时间。旧版本 1 只在内存转换，重新保存创建新修订，不改历史摘要。选择状态、草稿、端口与连接状态不保存。

配置保存在明确目标任务的 visualizations 区域，只包含引用和参数。保存不复制网格、不自动截图、不新增 Dojo 任务版本。重新打开时核验原数据修订；缺失或变化需显式重新绑定。

## 9. 导出

顶部动画默认 MP4、1280×720、24 fps，可选择起止实际时间步、步长、正反向以及活动视图或整个布局。每个选定时间步一帧；fps 只决定播放速率，不改变物理时间。

输出使用已保存修订，未保存修改先保存。后台输出独立场景，提供进度、取消和下载。PNG、PNG 序列、CSV 和实际操作 WebM 从导出菜单进入；只有显式输出才创建文件，失败或取消不发布成功清单。

## 10. 典型流程

导入结果 → 选基础显示 → 选择着色字段 → 创建分析对象 → 编辑并应用 → 分屏与时间对比 → 保存配置 → 显式导出。

会话内导入由宿主选择与校验来源，在现有工作区追加；失败保留原场景、相机与草稿。Dojo 可选择同项目不同任务来源，保存到一个明确目标任务。浏览器不能指定任意服务端路径。

## 参考图视觉落地

工作台采用蓝白图标工具带、左上对象树、左下加高可滚属性表单和深蓝灰大视口。宽屏左栏约占四分之一；首行分析工具80px、视图工具68px、标签39px，嵌入时贴合父框并去掉平台外层留白。后处理三维页保持 820px 独立滚动窗口，对象树和三维窗口必须露出，不能只剩工具条，页面可向下滚动。坐标分为独立 XYZ 输入，法向无量纲。窄窗口通过更多分析及视角菜单保留操作。导出进度为可关闭提示，不改变布局高度。

展示真实导入结果；参考图的泵模型、预建物理量节点和云图创建按钮不作为占位内容加入。视觉截图与真实操作单独核验，不能由构建通过或旧功能测试推断布局符合参考图。
