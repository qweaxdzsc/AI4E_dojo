# Dojo 原子能力简表

按 applications 的 rawprep、trainprep、train、model、post 五类归并，共 **20 项业务粒度的能力**。辅助函数随所属能力合并，模型内部算子不在这张表中展开。

| 分类 | 原子能力 | 作用 |
| --- | --- | --- |
| rawprep 原始数据处理 | 数据接入 | 下载、按需解压并读取已支持的原始数据文件。 |
| rawprep 原始数据处理 | 字段提取 | 提取坐标及所需物理场，明确字段归属与身份。 |
| rawprep 原始数据处理 | 几何特征计算 | 按需计算表面法向、最近顶点距离或点到面距离。 |
| rawprep 原始数据处理 | 数据筛选 | 按有效点、表面重合等规则标记或筛选，保持字段对齐。 |
| rawprep 原始数据处理 | 数据保存 | 将处理结果保存为 PT/Zarr 等张量数据或保留拓扑的网格数据。 |
| trainprep 数据准备 | 数据集准备 | 按已有清单和分片选择、读取训练及评估样本。 |
| trainprep 数据准备 | 归一化准备 | 确定并冻结统计参数，应用标准化或 MinMax 等变换，按需保存归一化数据。 |
| trainprep 数据准备 | 采样与分块 | 设置点采样或跨步分块方式，供训练和推理使用。 |
| trainprep 数据准备 | 输入与批次组织 | 绑定模型输入、目标和工况，将样本组织成模型可消费的批次。 |
| train 训练 | 损失设置 | 设置监督字段、比较方法及各项权重。 |
| train 训练 | 优化设置 | 设置优化器、学习率调度、梯度累积与裁剪等更新规则。 |
| train 训练 | 训练执行 | 按预算执行训练、验证和选优，按需启用 EMA，并记录进度。 |
| train 训练 | 检查点与恢复 | 捕获、保存训练状态，并从兼容的检查点继续训练。 |
| model 模型 | 模型构建与查看 | 选择模型、配置结构并创建实例，按需用真实输入生成结构视图。 |
| model 模型 | 权重初始化 | 使用模型默认初始化，或加载已有初始权重。 |
| model 模型 | 参数冻结 | 指定保持不更新的参数，确定参与训练的参数范围。 |
| post 后处理 | 模型推理 | 恢复推理权重，对指定点或完整物理域生成预测。 |
| post 后处理 | 物理量还原 | 使用冻结的归一化参数，将预测恢复为物理量。 |
| post 后处理 | 结果评价与比较 | 将预测与真值对齐，计算误差指标，或对满足身份和单位要求的场计算差值。 |
| post 后处理 | 结果处理与导出 | 将预测回贴网格，按需提取表面或切面，导出点云、网格或数组。 |

这里的“原子”是便于组合和讨论的业务单元，不要求每项只有一个函数或独立进程。阶段之间复用同一底层实现；采样、归一化等也可能在训练迭代或后处理中执行。具体模型支持的选项仍以当前实现为准，这张表不表示任意组合均可运行，也不表示拖拽节点已实现。

模型内部另有可选 FLARE++ 动态路由注意力，归入“模型构建与查看”下的计算组件，不额外计为第 21 项业务能力。它不是输入预处理，不自动替换已有网络，也不表示平台开放新模型。[使用示例与边界](agent-help/user-components/network.md)提供公开调用方式。

详细归并及源码对应关系保留在 [合并清单](abilities-merged.md) 与 [原始能力清单](abilities-inventory.md)。

### 脚本物理场分析与输出

- 后处理分析：字段选择、切片、剖切、矢量、流线、等值面及探针采样。
- 图片：物理场和剖面曲线，显式视角、色带、范围；可替换普通 Python 函数。
- 文件：PNG、VTP/VTU、CSV/JSON 分别保存，可独立读回。
- 指标：九项误差复用原评价，区域统计采用有效实体等权口径。

GenCP 增加原生时空数组、流匹配路径与目标、可恢复迭代流、异形场条件映射、同步/顺序积分和逐帧评价；源码逐项见详细清单，真实验收见仓库 GenCP 专项记录。
