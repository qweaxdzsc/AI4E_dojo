## Neumann：案例相同，主要预算相同，训练算子不同

论文是附录 C.4，PDF 第30–32页，式(71)–(74)、表1。比较的确是同一个一维扩散案例：`u_t = nu*u_xx`，初值 `cos(pi*x)`，两端零导数。

| 核查项 | 文献 | 原仓库实际代码 | Dojo 当前实现与差距 |
|---|---|---|---|
| 参数输入 | 扩散系数 ∈[0.1,1.5] | 单输入 nu，同范围 | 一致；没有误用另一个扩散案例 |
| 空间/时间域 | x∈[0,1]、t∈[0,1] | 相同 | 相同 |
| 标签方程 | cos(pi*x) exp(-nu*pi²*t) | 相同解析式 | 相同解析式，计算精度不同 |
| 训练/测试实例 | 50 / 10 | 50 / 10 | 50 / 10，一致 |
| 观测网格 | C.4 未明确128点 | 128×128，包含两端 | 128×128，包含两端；源码补充，不能说论文明确给了128 |
| 坐标/标签精度 | 未指定 | NumPy FP32 坐标上计算，标签 Torch FP32 | NumPy FP64 坐标/标签；训练转FP32。标签并非逐值相同 |
| 随机数/名单 | 均匀抽样，未给种子/名单 | seed42，连续 MT19937，先50训练再10测试 | seed42，SeedSequence分两流+default_rng。相同种子不等于相同数据 |

| 输入顺序/归一化 | 单参数 | [nu]，无归一化 | [nu]，无归一化；一致 |
| 网络 | 3层全连接，隐藏128 | 1→128→128→1600，ReLU | 同尺寸和激活，未删减控制输出 |

| 二阶导数 | 式(12)的次数/阶数记号仍待确认 | 三项平方分母递推，不等于标准二阶样条导数 | SciPy标准二阶导数；不能只乘35²就认为恢复了源递推 |

| 初边界条件 | 初值与Neumann罚项，权重2 | 初值MSE、左右导数MSE分别相加，再乘2 | 软条件、每边单独MSE和同权重；形式一致，但导数不同 |
| PDE/数据权重 | 1 / 5 | 1 / 5 | 1 / 5，无需随意加大数据权重 |
| 配点 | 一般损失公式 | 完整128×128网格，包括初边界 | 同完整网格；未少采样 |
| 更新/轮次 | 5000轮；通用Algorithm1画在逐实例循环内更新 | 每轮50实例损失求和，一次backward/Adam，共5000更新 | 每实例backward累积、整轮一次Adam，共5000更新；数学聚合相同，浮点累积顺序不同。论文通用算法与源码冲突仍保留 |
| Adam | 具体案例未完整给超参 | lr=.001，betas(.9,.999)，无裁剪/衰减/调度 | 相同 |

**已验证的影响，而非猜测：** 历史诊断固定同一系数张量、同一 Dojo 样本 `nu=1.3834418206`，仅更换算子，PDE MSE 从 **0.46928346** 变为 **1,101,159.375**；两端导数平方和从 **0.4696458** 变为 **1777.5471**；数据 MSE 两者均约 **0.02562222**。这是损失相对尺度变化的直接证据。它没有证明随机名单或初始化完全无影响，也不构成调权重授权。

历史实际误差：Dojo **0.96474202**，原仓库完整基线 **0.01875177**，论文 **0.01932**。原仓库已经与论文接近（相对论文约低2.94%），不能继续归类为“原仓库 Neumann 没跑准”。Dojo 使用物理导数的变体不能等同于原实现。

## Advection：输入范围相同，但硬初值和一阶导数改变了问题

论文主文5.2、附录D.2，PDF第10、33、35页，式(19)/(20)、图5/13。是同一个周期正弦传输案例，参数为速度和相位，没有换案例。

| 核查项 | 文献 | 原仓库实际代码 | Dojo 当前实现与差距 |
|---|---|---|---|
| PDE | u_t + beta*u_x = 0 | 相同正号 | 同号；不是Burgers正负对流冲突 |
| 输入范围 | beta∈[.5,1.5]、phase∈[0,2pi) | 同范围；注释中的[.8,1.2]是过时注释 | 同范围，没有按错误注释缩窄 |
| 固定初值特征 | 单正弦 | 波数2pi、振幅1、变化相位 | 同数学初值；不需要把固定波数/振幅误认为缺失输入 |
| 网络输入顺序 | 速度与相位 | [beta, phase] | 相同、无归一化 |
| 空间/时间域 | x∈[0,1]、t∈[0,2] | 相同 | 相同；时间跨度2参与导数尺度换算 |
| 训练/测试 | 100训练，30测试统计 | 100 / 30 | 100 / 30，一致 |
| 网格 | 100空间×100时间点 | 相同、含端点 | 相同、含端点 |
| 数据解析式 | sin(2pi*((x-beta*t) mod 1)+phase) | 显式mod1；FP64计算后存FP32 | sin(2pi*(x-beta*t)+phase)，FP64标签。数学周期等价、数值运算不逐值等价 |
| 坐标和参数存储 | 未指定 | x/t、beta/phase、标签转FP32 | 坐标/标签为FP64，参数Python float；模型输入转FP32，lifting又使用保存的phase |
| 随机名单 | 均匀抽样；未公开精确名单 | 原notebook没显式seed；此次原基线入口补seed42，MT19937连续流 | seed42，训练/测试两个default_rng流；两次抽样顺序相同但随机算法不同 |
| 首个训练参数 | 未公开 | beta=0.8745400906、phase=5.9735140800 | beta=1.4167441576、phase=5.7238980451 |
| 首个测试参数 | 未公开 | beta=1.1420316696、phase=.5286669731 | beta=.9674907800、phase=.2918470237 |
| 网络 | 3层全连接、ReLU | 2→64→64→22500 | 同结构；隐藏64由源码补足，不冒称论文D.2明确给出 |
| 控制网格/次数 | 150×150、d=5 | 同 | 同，无需减少控制点“稳定训练” |
| 初值执行 | 控制系数赋值思路 | 取标签第0行，np.interp从100点插到150点，覆盖控制行 | 解析lifting：sin(2pi*x+phase)+(t/2)*spline。不是同一个场重建算法 |
| 初值梯度 | 赋值后被覆盖项不学习 | 首行150个输出被覆盖、对应参数无场梯度 | 全部22500个输出参与(t/2)*spline，u_t还含spline/2；自由函数空间不同 |
| 一阶导数 | 物理坐标PDE | 参数区间[0,145]的导数直接入PDE | 物理时间导数缩放145/2=72.5、空间导数缩放145；两轴比例不同，且lifting附加导数项 |
| 二阶导数 | PDE不含二阶 | 原训练只用B'，忽略返回的B'' | Dojo虽计算B''，这例PDE不用；不能将二阶递推差异说成它的主要失准原因 |
| 基函数端点 | 未给完整数值过程 | np.zeros默认FP64逐项累加参数坐标，值基末项覆盖 | SciPy物理坐标、单侧导数；与梯形FP32累加不能混为一谈 |
| PDE/数据损失 | 一般MSE定义 | PDE MSE + 10×data MSE | 相同权重/归约；额外初值与周期罚项权重为0 |
| 周期条件 | 周期解/周期边界 | 没有额外周期罚项 | 保存周期配对并监测，权重0；没有额外改变优化目标 |
| 配点/更新 | 完整细节由源码补足 | 全100×100网格，含初边界；每实例更新 | 相同；2000轮×100实例=200000更新，未减预算 |
| 优化器 | D.2未给完整设置 | Adam .001、(.9,.999)、无衰减/裁剪 | 相同 |
| 评价 | 30例相对L2统计 .1444±.1352 | 全时空L2后对30例统计 | 同类型口径，但数据名单不同 |

**影响判断：** 初值lifting是确定的算法替换；一阶物理缩放使两项的相对比例从原实现的1:beta变为72.5:145beta（仅指同一参数基函数的链式换算，不包括lifting附加项）。因此它不只是整体乘一个loss常数。随机名单/坐标精度也不同，但当前没有逐因素消融，不能给各因素编造“贡献百分比”。

历史实际误差：Dojo **0.30085132**，原仓库完整基线 **0.10427002**，论文 **0.1444±0.1352**。原仓库单次结果低于论文均值约27.79%，并不表示失败；论文较大的样本差异和不同测试名单意味着也不能仅凭落入均值±标准差就宣布复现通过。Dojo 与原实现的算法差距是真实存在的。

## 接下来哪些可以对齐，哪些必须先确认

1. **不涉及论文数学冲突的实现差距**：若继续要求原代码设置等价，应统一参数名单和随机流、标签生成精度/取模路径、模型初始化状态、Advection首行插值赋值、输入顺序及全点评价。此次只核查，未擅自修改这两例。
2. **必须先确认的冲突**：原参数空间导数/端点/Neumann二阶递推，与论文物理方程/式(12)如何取舍；Neumann通用Algorithm1的逐实例更新与案例源码整轮更新如何取舍。不能通过改学习率、权重或预算遮住这些差异。
3. **验证门槛**：固定同一输入和初权重，对照B/B'/B''（Advection训练只需B/B'）、覆盖后的系数、逐点残差、分项loss、梯度及Adam一步。之后才进行完整训练和精度比较。
