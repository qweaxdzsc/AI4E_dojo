当前 Dojo 是加入数学修正和实现替换的 PI-BSNet 变体，不能称为原仓库算法的等价迁移。主要差距不在学习率或轮次，而在样条导数、初值与控制系数参数化、数据求解器、Burgers 残差及损失、部分案例更新语义。

“与论文完全一致”和“与仓库完全一致”目前不能同时成立：来源本身有冲突。不能继续采用部分按论文、部分按代码、部分自行修正，却统一标记为已对齐的方式。

## 一、明确的结构和数据算法差距

### A1 对流–扩散：恢复初始控制行与576维输出

论文第9页式(18)、第31页 Algorithm 1 要求通过控制系数赋初边界。原 `convection_diffusion.py` 的 `ControlPointNet` 输出 `(25-1)*(25-1)=576` 个系数；训练先置初始行为0，再置右边界为1，最后填入其余自由系数。

Dojo 仅固定右边界，初始行仍可训练，输出为 `25*24=600`；初值权重为0。仅监测初值并不等于原来的控制系数赋值。

补齐：恢复576维输出、初始行赋值、右边界优先的交角规则及对应索引布局。需要修改模型和组件构建，不能只加一个初值 loss。验收同一输入/权重下的自由系数、完整控制网格和梯度掩码；不要把赋控制系数进一步夸大为所有不连续交角附近都逐点严格满足初值。

定位：[原模型](/Users/zonghui/work/new_code_project/PI-BSNet/src/convection_diffusion.py:414)、[原训练赋值](/Users/zonghui/work/new_code_project/PI-BSNet/src/convection_diffusion.py:493)、[Dojo模型](/Users/zonghui/work/new_code_project/AI4E_Dojo/packages/ai4e-contrib/ability/model/pibsnet/model.py)。

### A2 Advection：取消解析 lifting，恢复控制行赋值算法

论文第6页及 Algorithm 1 描述控制系数赋值。原 `advection.ipynb` 的 `assign_first_row_direct` 将100个初值标签通过 `np.interp` 插值到150个控制位置，覆盖网络输出的首行。网络仍输出150×150个数，首行输出被覆盖。

Dojo 使用 `sin(2πx+phase)+(t/2)*spline(t,x)`，同时改变 u、u_t、u_x、u_xx。两者函数空间、梯度和硬约束方式不同，即使 lifting 的解析初值更精确，也不是原算法。

补齐：在唯一 PI-BSNet 组件中恢复首行覆盖、插值坐标、标签精度及 train/post 同一求值路径。不能仅删除 lifting 而漏掉首行赋值。论文“任意非恒定初值可直接赋系数并精确满足”的一般性表述需要另行验证；仓库这里实际做的是插值后赋系数。

定位：[原Notebook](/Users/zonghui/work/new_code_project/PI-BSNet/src/advection.ipynb)，`BetaPhaseControlPointNet`、`assign_first_row_direct`；[Dojo evaluate_fields](/Users/zonghui/work/new_code_project/AI4E_Dojo/packages/ai4e-contrib/ability/model/pibsnet/model.py:69)。

### A3 梯形：恢复初始平面、完整输出头和轴布局

论文第35–36页式(77)/(83)及 Algorithm 1 要求初始内部0、四边1。原 `BSplineNet_a` 输出完整 `[t,x,y]` 系数；`compute_loss_pde_data_icbc` 覆盖初始平面和四个空间边界，再用 `einsum` 输出 `[t,y,x]`。

Dojo 只固定四边，没有固定初始内部；删除固定边界的输出神经元，仅输出自由系数，布局为 `[t,eta,xi]`。在论文100×20×20控制网格下，原结构输出40000，覆盖后实际参与场学习的系数为99×18×18=32076；当前 Dojo 输出100×18×18=32400。输出头形状、随机初始化消耗和自由系数都不同。

补齐：若要求原网络结构一致，恢复完整40000维输出，再按原顺序覆盖初边界，并显式转换 x/y 与 eta/xi 轴；若选择仅输出自由系数，必须先证明权重/梯度映射等价，不能默认为同结构。必须先恢复初始平面，不能以 IC 权重0的监测代替。

定位：[原Notebook](/Users/zonghui/work/new_code_project/PI-BSNet/src/diffusion_trapezoid.ipynb)，`BSplineNet_a`、`compute_loss_pde_data_icbc`；[Dojo模型](/Users/zonghui/work/new_code_project/AI4E_Dojo/packages/ai4e-contrib/ability/model/pibsnet/model.py)。

### A4 对流–扩散数据：CDF替换了数值积分

论文第31/33页式(75)明确使用数值积分。原 `ground_truth` 使用 SciPy `quad`；Dojo 使用等价闭式 CDF、`ndtr/log_ndtr`。数学解可等价，但计算算法、舍入和极端值处理不是同一过程。

若要求数据生产算法也一致，应恢复原数值积分及端点分支，或将闭式形式列为“经证明允许的等价实现”，不能无记录替换。原脚本生成100例后加载40例；论文及Dojo直接生成40例，训练规模一致，但生成流程和随机数消耗不同。

定位：[原积分](/Users/zonghui/work/new_code_project/PI-BSNet/src/convection_diffusion.py:86)、[Dojo生成器](/Users/zonghui/work/new_code_project/AI4E_Dojo/packages/ai4e-contrib/application/datasets/convection_diffusion/generate.py)。

### A5 Burgers 数据：周期网格和积分器接口改变

原 `burgers.ipynb` 数据单元使用 `X=linspace(0,10,1000)`，包含两端；FFT 却使用 `d=0.01`。时间点为 `linspace(0,8,320)`，积分用 `odeint(..., mxstep=5000)`。

Dojo 使用不重复右端点的周期网格 `[0,10)`，FFT间距一致为0.01；积分改为 `solve_ivp(method='LSODA', rtol=1e-7, atol=1e-9)`。同属 LSODA 不能证明容差、步进、初值网格和返回值一致。论文第41页没有给出这些求解器细节，只给方程、参数域和初值。

若严格继承源码缺省细节，需要恢复网格、odeint容差默认、mxstep和标签存储/轴转置；原网格与FFT间距不一致必须明示。若保留物理修正，则应明确这是偏离原数据算法的研究选择，不宣称原流程复现。

定位：[原Notebook](/Users/zonghui/work/new_code_project/PI-BSNet/src/burgers.ipynb)，数据代码单元1/3、`burg_system`；[Dojo求解器](/Users/zonghui/work/new_code_project/AI4E_Dojo/packages/ai4e-contrib/application/datasets/burgers/generate.py:10)。

### A6 梯形数据：前向Euler被替换，离散算子也不同

论文第36页明确：前向 Euler、Δt=0.001、21×21空间网格。原 `solve_pde_trapezoid_mapped_grid` 用显式 Euler、逐行可变dx及固定dy的二阶差分，没有完整映射的混合/一阶项。

Dojo 使用完整变换的稀疏空间算子，加 `expm_multiply` 矩阵指数积分。输出仍为1001个时间片不表示内部采用Δt=0.001的Euler步进。此项同时偏离论文明确的时间算法和源码空间模板。

补齐：首先恢复论文指定的Euler步长和时间算法；空间算子必须标明采用论文式(81)的完整变换还是源码近似模板。二者存在来源冲突，不能只把expm改成Euler就宣布所有数据算法一致。若采用源码模板，应保存单步更新夹具并逐网格点校验；若采用完整算子，应标明对代码的偏离。

定位：[原Notebook](/Users/zonghui/work/new_code_project/PI-BSNet/src/diffusion_trapezoid.ipynb)，`solve_pde_trapezoid_mapped_grid`；[Dojo求解器](/Users/zonghui/work/new_code_project/AI4E_Dojo/packages/ai4e-contrib/application/datasets/diffusion_trapezoid/generate.py:10)。

## 二、论文与源码冲突，必须先确定唯一目标

### B1 五例共用的样条导数：坐标、递推和端点三项分别对齐

原源码用 `[0,n_cp-degree]` 的节点参数坐标构建基矩阵，直接把参数导数当作 PDE 的 t/x 导数，没有物理区间缩放。Dojo 在物理区间直接生成 SciPy BSpline 导数。

仅对正确的一阶链式变换，换算因子就为 `(n_cp-degree)/(high-low)`：CD时间2.2、空间22/(a+10)；Neumann两轴35；Advection时间72.5/空间145；Burgers时间12/空间9.6；按论文控制网格的梯形时间97/空间17。二阶导数还涉及平方因子，但原二阶递推不同，不能只乘因子修复。

原 `BsFun_second_derivative` 使用三个基函数及平方分母表达式；Dojo 使用SciPy标准导数。原零次基为半开区间，最后值基单独置1；导数没有相同端点修正，Notebook逐项累加参数坐标还可能有舍入差别。Dojo采用域内单侧导数。端点又进入完整PDE和Neumann边界损失，因此这不是无关紧要的实现细节。

PDF第6页式(12)印刷系数为 `(d-1)!/(d-p-1)!`，原源码一阶系数是d、二阶是d(d-1)，其下标/分母写法也不能直接与Dojo声明等价。应将“论文公式字面值”“代码行为”“标准B样条导数”作为三份待核对定义，不能仅凭SciPy正确就说已忠实实现印刷公式。

补齐：固定节点、同一控制张量，分别输出B/B'/B''以及端点、混合导数矩阵，核对来源；原算法迁移应忠实复现原矩阵行为，数学修正要单独记录。此处不能同时要求保留当前修正且与原仓库完全相同。

定位：[原CD样条](/Users/zonghui/work/new_code_project/PI-BSNet/src/convection_diffusion.py:37)、[原Neumann样条](/Users/zonghui/work/new_code_project/PI-BSNet/src/neumann_bc.py:121)、[Dojo样条](/Users/zonghui/work/new_code_project/AI4E_Dojo/packages/ai4e-contrib/ability/model/pibsnet/spline.py)。

## 四、五案例应该补到什么状态

1. **对流–扩散**：恢复初值控制行和576维输出；决定积分实现是否必须逐步相同；锁定样条导数和更新粒度冲突；固定参数名单与初始权重。
2. **Neumann**：网络形状、软初边界权重基本与代码一致；核心工作是导数定义、端点、更新粒度、坐标精度和随机流。40×40明确标代码来源。
3. **Advection**：恢复原首行插值赋值，取消解析lifting；对齐时间/空间导数尺度、端点和初始权重。现有网格及主要预算无须随意调整。
4. **Burgers**：确定论文正号和MSE与代码负号和L2的取舍；还原或明确批准数据网格/积分器差异；审定IC实现。只改符号不能称全算法一致。
5. **梯形**：恢复初始平面和输出头/轴映射，恢复Euler；解决数据空间离散冲突；保留论文50例/100×20×20/0.001权重及式(84)训练近似。

## 五、不依赖最终精度的验收链

验收目标是相同输入和状态下执行同一个离散算法，允许预先声明的浮点容差；不是要求重新训练后得到论文误差。

1. **基准契约**：先填完每项来源和冲突决策；冲突未决时整体状态为“尚未定义唯一目标”。
2. **数据一步**：固定一个参数实例，比较坐标、初值、离散算子和一次时间步；再比较完整标签。解析式替换必须有明确等价许可与边界验证。
3. **样条一步**：相同节点和控制张量比较B、B'、B''、物理缩放、端点、轴顺序及完整场。
4. **模型一步**：映射同一初始权重，比较MLP输出、覆盖后的控制系数、自由系数数量和被覆盖输出梯度。
5. **目标一步**：比较每个配点的残差、各分项loss、归约除数与加权总loss；包括初值、Neumann两边界和无额外周期罚项。
6. **更新一步**：比较全部参数梯度、Adam一阶/二阶矩、step计数和更新后权重；CD/Neumann必须覆盖完整逻辑更新组。
7. **流程交接**：固定少量更新验证恢复后下一步相同，独立post使用相同重建算法；新准备资产与旧检查点兼容性分别判定。

已有`test_pibsnet_physical_reference.py`证明当前Neumann目标与SciPy物理导数目标一致；它不是与原错误/不同导数分支等价的证据。已有同预算精度报告也不能代替以上逐层门禁。

这次核查不启动调参、长训或改算法。补齐顺序应是：先解决来源冲突，再修结构/生成器，最后执行逐步等价验收；当前精度报告保留作为历史变体实验。
