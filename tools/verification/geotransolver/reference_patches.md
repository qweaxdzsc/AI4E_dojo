# 独立参考适配

锁定 PhysicsNeMo aa19b58a129f8d1fabdcaa41c6ca85d5dc01aae1。reference.py 对每个来源文件逐字核对 git show，单独执行原函数/类定义；去掉的仅是第三方导入、框架元数据。实际数值类不引用 ai4e_core 或 ai4e_contrib。

支持普通 PyTorch GALE；关闭 TE、AMP、CUDA分布式、激活检查点。CPU/MPS统一float32。半径查询选择上游 torch backend，MPS的距离查询显式在CPU；查询分块和身份缓存仅为执行优化，独立对照邻居顺序及坐标。

Darcy 用公开MAT，先float32后全局标量统计，1000训练/200评价，batch4，末批保留。相对L2先逐样本计算再平均。学习率日程沿原1000轮，不按短训目标压缩。

保险杠公开分片124/7，11个共同时间0..100ms，预测10帧，原多余110ms帧仍物理保存。上游VTP正则仅匹配t0.000导致漏帧，需要数值时间解析全部位移字段；同一共同时间窗口应用到动态目标，不重复末帧填充。工况及五通道顺序固定，归一化保持原逐样本float32平方矩及两处epsilon。

上述属于工程实验协议，与论文保险杠135例、50帧或原Transolver Darcy 0.0057不是同一精度实验。不得将短训对照写为论文复现。
